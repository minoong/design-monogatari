# React / Next.js

When writing or refactoring components in `apps/` or `packages/ui/`:

1. Invoke the `vercel-react-best-practices` skill
2. React 19 functional components, named exports
3. `@repo/ui` imports via subpath: `@repo/ui/button`
4. No barrel files

Reference: `packages/ui/src/button.tsx`
