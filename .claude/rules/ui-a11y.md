# Accessibility

When creating or editing UI:

1. Invoke the `accessibility` skill
2. For fixes: `fixing-accessibility`
3. Semantic HTML, keyboard focus, labels for forms, alt text for images
4. Review requests: `web-design-guidelines`

Do not skip a11y for "quick" components in `@repo/ui`.
