# Web performance

When optimizing or building features in apps or `@repo/ui`:

1. `vercel-react-best-practices` skill — React/Next patterns
2. `performance` skill — Lighthouse, loading strategy
3. `core-web-vitals` skill — LCP, INP, CLS
4. Motion: `fixing-motion-performance` skill

After changes, do not wait to be asked: `ui-verifier` subagent (light/dark) if the UI changed, then `pnpm verify`.
