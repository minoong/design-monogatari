# 견적 화면은 제네시스식 위저드로

> 제네시스와 현대의 차량 견적기를 직접 눌러 보고, 무엇을 따르고 무엇을 고칠지 정한 기록입니다.

## 결정

BMW X5 견적 앱은 **제네시스식 위저드**로 만듭니다. 단계마다 화면이 있고, 상단 스테퍼의 모든 항목이 링크이며, 오른쪽 옵션 패널 아래에 총액이 고정됩니다. **선택한 내용 전체를 URL에 담아서** 링크 하나로 견적을 공유하고 복원합니다.

## 어떻게 조사했나

두 사이트를 실제 고객처럼 끝까지 눌러 봤습니다. 로그인, 개인정보 입력, 구매는 하지 않았습니다. 브라우저에서 보이는 것과 사이트가 공개로 내려주는 JSON, 네트워크 요청만 근거로 삼았고, 확인하지 못한 것은 아래에 따로 적었습니다.

## 두 사이트 비교

|             | 제네시스 (G90 LWB, GV80)                                                                                                                   | 현대 (그랜저 Hybrid)                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------ |
| 구조        | 트림과 파워트레인 변형은 **별도 모델**입니다. 모델 안은 엔진, 구동, 외장, 휠, 시트, 내장, 가니쉬, 선택 품목, 액세서리, 결과의 위저드입니다 | 모델 선택 후, 외장·내장·옵션·액세서리가 **한 페이지 스크롤 구역**입니다. 서브 스테퍼는 앵커 점프입니다 |
| URL 상태    | **전부 담깁니다.** 7글자 `code`(단계별 위치 코드)와 3글자 `packages` 연결. 링크로 완전히 복원됩니다                                        | 거의 안 담깁니다. 새로고침하면 기본값으로 돌아갑니다                                                   |
| 규칙 처리   | 옵션 JSON의 `filter`, `exclude`, `include`를 **브라우저에서** 처리합니다                                                                   | 선택을 바꿀 때마다 서버에 뭅니다. 색 하나를 누르면 API 7건과 프레임 이미지 60장이 오갑니다             |
| 차량 이미지 | 색마다 정적 이미지 한 장입니다. 휠과 옵션은 차에 반영되지 않습니다                                                                         | 360° 이미지 61장을 갈아끼웁니다. 이미지는 "최고 트림 전체 옵션 기준"이라고 적혀 있습니다               |
| 가격        | 하단 고정, 약 0.5초 카운트업, 항목별 연필 링크가 있는 견적 요약                                                                            | 헤더에 세제 혜택 전/후 두 줄, 변경은 즉시 반영                                                         |
| 결과        | 항목별 변경 링크, 재견적, 프린트, PDF, 공유, 이메일, 과세·면세와 지역별 부대비용                                                           | 저장, 이메일, 공유, PDF. 탁송·등록비·할인·결제는 로그인 뒤에 있습니다                                  |

## 선택에 따라 화면이 어떻게 바뀌나

두 사이트에서 직접 확인한 규칙입니다. 우리 규칙 엔진은 이 종류를 모두 다룹니다.

| 규칙                       | 실제 사례                                                                | 화면 반응                                                                                         |
| -------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| 필수 동반                  | 4인승 시트를 고르면 뒷좌석 컴포트 패키지(+500만원)가 자동으로 추가됩니다 | 안내 모달. 해제하려고 하면 같은 모달로 막힙니다                                                   |
| 상위 선택이 바뀔 때 재매핑 | 엔진을 바꾸면 구동과 휠이 새 엔진에 맞게 다시 정해집니다                 | **이전 선택과 현재 선택을 나란히 보여 주는 확인 모달.** 확인하기 전에는 가격도 URL도 그대로입니다 |
| 파생 값                    | 내장 색을 바꾸면 가니쉬가 어울리는 것으로 따라 바뀝니다                  | URL 코드의 두 위치가 함께 바뀝니다                                                                |
| 패키지가 다른 옵션을 포함  | 한 패키지가 HUD와 드라이빙 어시스턴스를 포함하면 둘은 체크된 채 잠깁니다 | 하나를 해제하면 확인 모달이 뜹니다                                                                |
| 대안 제안                  | 드라이빙 어시스턴스를 고른 뒤 HUD를 더하면                               | "패키지가 더 저렴합니다" 제안 모달                                                                |
| 트림별 가용성              | 내장 색 11종 중 트림마다 3~4종만 고를 수 있습니다                        | 비활성 스와치에 사유가 붙고, 누르면 트림 변경을 제안합니다(+4,490,000원)                          |
| 색과 색의 제약             | 특정 내장은 외장 두 색에서만 가능하고 반대 방향도 성립합니다             | 반대편 목록이 다시 계산됩니다                                                                     |
| 상호 배타                  | 시트 컴포트Ⅱ와 빌트인 캠, 선루프와 스마트 비전 루프                      | "A를 빼야 B를 고를 수 있습니다" 교체 모달                                                         |
| 선행 조건                  | 20인치 휠은 플래티넘 패키지가 먼저 필요합니다                            | 추가 확인 모달. 패키지를 빼면 휠이 **알림 없이 사라집니다**                                       |
| 단순 가격 변동             | 무광 +80만원, 가니쉬 +100만원                                            | 총액이 갱신됩니다                                                                                 |
| 최종 검증                  | 탁송지를 비우고 완료하면                                                 | 안내 모달, 완료 버튼 비활성                                                                       |

## 무엇을 따르고 무엇을 고치나

**따릅니다**

- 위저드와 링크 스테퍼, 고정 총액과 이전/다음
- 선택 전체를 URL에 담기
- 규칙을 브라우저에서 즉시 처리하기 (서버 왕복 없음)
- 이전/현재 비교 모달, 대안 제안 모달
- 항목별 "변경" 링크, 지역별 부대비용 표, 프린트

**고칩니다**

- 비활성이거나 제거된 옵션을 **이유와 함께 화면에 바로** 보여 줍니다. 호버 툴팁에 기대지 않습니다
- 자동으로 바뀐 것은 **모두 알립니다.** 선행 옵션을 빼면 의존 옵션이 조용히 사라지던 동작은 따르지 않습니다
- 총액이 바뀌면 스크린 리더에 알립니다 (`aria-live`)
- 옵션 그룹은 방향키로 이동하고, 비활성 항목에 탭 정지가 두 번 생기지 않게 합니다
- 모달에 `aria-labelledby`를 달고, 페이지에 `main`과 건너뛰기 링크를 둡니다
- 외장 색은 **3D 모델에 실제로 반영**합니다. 두 사이트는 정적 이미지거나 "참고용" 이미지입니다

## 확인하지 못한 것

- 두 사이트의 할인·포인트·결제 화면은 로그인이 필요해서 보지 못했습니다.
- 이메일 발송, 구매 상담 신청, 서버 PDF 생성은 실행하지 않았습니다.
- 시트와 내장 이미지가 바뀔 때의 애니메이션 시간은 재지 않았습니다.
- 모달 안의 키보드 동작, 대비 비율, 스크린 리더 읽기는 확인하지 못했습니다.
- 옵션 세 개 이상이 얽힌 조합은 시도하지 않았습니다. 규칙은 두 개씩 짝지어 확인했습니다.
- 조사 도구가 제네시스 페이지에서 현대 견적 페이지로 저절로 이동한 일이 한 번 있었는데 원인을 찾지 못했고 다시 일어나지 않았습니다.

## 이 결정이 가져오는 것

- 선택 상태가 URL에 있으니 공유와 복원이 쉽고, 규칙 엔진을 순수 함수로 만들어 테스트할 수 있습니다.
- 단계마다 화면이 있어서 현대식 한 페이지보다 화면 수가 많습니다. 대신 규칙의 영향이 단계마다 드러나서 설명하기 좋습니다.
- 카탈로그는 가상 데이터입니다. "비공식 포트폴리오이며 BMW와 무관합니다"라는 안내를 화면에 둡니다. 세금 공식은 단순화한 규칙이고 그 사실을 문서에 적습니다.
