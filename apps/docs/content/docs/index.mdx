design-monogatari는 Apple에서 영감을 받은 디자인 시스템입니다. 조용한 크롬에 강조색은 Action Blue 하나만 쓰고, 폰트는 Geist입니다. 접근성과 동작이 필요한 곳(Dialog, Label, Slot)은 **Radix Primitives**를 쓰고, 스타일은 **Tailwind CSS v4**와 자체 토큰으로 만듭니다. 움직임은 UI에 **Motion**, 스크롤 연동에 **GSAP**을 나눠 씁니다.

## 지금 읽을 수 있는 것

이 사이트는 골격 단계입니다. 아래는 순서대로 채워 갑니다.

| 영역                                                      | 상태                                                                                                                  |
| --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 파운데이션 (색, 타이포그래피, 라운딩, 보더, 모션, 아이콘) | [색](/docs/foundations/colors), 타이포그래피, 라운딩, 보더, 모션, [아이콘](/docs/foundations/icons) 페이지가 있습니다 |
| 컴포넌트 (Button, Dialog, Field 등)                       | [Button](/docs/components/button)부터 PackageRow까지 열네 개가 있습니다                                               |
| 유틸리티                                                  | [cn](/docs/utilities/cn)이 있습니다                                                                                   |
| Claude Code 에이전틱 개발 워크플로우                      | [AI 워크플로](/docs/ai-workflow)에 지침, 에이전트, 스킬, 훅, 루프를 정리했습니다                                      |

## 빠른 설치

컴포넌트는 shadcn 레지스트리로 배포합니다. 프로젝트에 파일이 복사되므로 설치한 뒤에는 자유롭게 고칠 수 있습니다.

<Callout title="shadcn이 처음이십니까?">
  레지스트리와 `shadcn` 명령은 [shadcn 문서](https://ui.shadcn.com/docs)에 설명되어 있습니다.
</Callout>

### 프로젝트 준비 [step]

**Tailwind CSS v4**를 쓰는 프로젝트가 필요합니다. `shadcn`은 **Radix 기반**으로 초기화해야 합니다.

```bash title="터미널"
pnpm dlx shadcn@latest init -b radix
```

<Callout type="warn" title="기본값(-d)으로 초기화하지 마십시오">
  요즘 `shadcn init -d`의 기본값은 Base UI입니다. 이때 CLI가 Radix의 `asChild`를 Base UI의
  `render=`로 바꿔서 `Dialog`가 깨집니다.
</Callout>

### 컴포넌트 설치 [step]

필요한 컴포넌트를 하나씩 추가합니다. 의존하는 컴포넌트와 테마는 함께 설치됩니다.

```bash title="터미널"
pnpm dlx shadcn@latest add minoong/design-monogatari/badge
```

### 사용 [step]

설치된 파일은 프로젝트의 `ui` 경로(기본 `@/components/ui`)에 있습니다.

```tsx title="app/page.tsx"
import { Badge } from '@/components/ui/badge';

export default function Page() {
  return <Badge>견적 저장 완료</Badge>;
}
```
