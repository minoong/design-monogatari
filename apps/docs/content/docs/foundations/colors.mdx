디자인 시스템의 강조색은 **Action Blue 하나**입니다. 오류를 나타내는 `destructive`는 상태 색이라서 브랜드 강조색이 아닙니다. 화면 컴포넌트에는 `bg-neutral-500`이나 `bg-blue-600`을 쓰지 말고, 아래 의미 토큰(`bg-background`, `bg-primary` …)만 쓰십시오. hex를 컴포넌트에 적지 않는 것도 같은 이유입니다.

## 의미 토큰

## 다크 모드

토큰 이름은 그대로 두고 `.dark` 아래에서 값만 바꿉니다. 컴포넌트에 `dark:bg-…` 같은 hex를 적지 않습니다. 다크 값은 [Radix 커스텀 팔레트](https://www.radix-ui.com/colors/custom?accent-dark=003CFF&bg-dark=000000)에서 왔고, 강조색은 `#003cff`, 배경은 검정입니다.

- 앱은 `next-themes`(`attribute="class"`, `defaultTheme="system"`)로 `<html>`에 `light` 또는 `dark` 클래스를 붙입니다. `html`에 `suppressHydrationWarning`이 필요합니다.
- 눌림 층(`dimmer`)은 항상 검정입니다. 다크에서 `foreground`를 쓰면 흰색으로 번쩍입니다.
- 이 사이트의 오른쪽 위 해/달 버튼으로 두 모드를 바꿔 보십시오.

## 지켜 주십시오

- 흰 배경에서 5~8% 검정, 검정 배경에서 5~8% 흰색 테두리는 보이지 않습니다. `border-border`를 쓰십시오.
- 두 번째 브랜드 강조색을 만들지 마십시오.
- 버튼, 카드, 다이얼로그에 그림자를 넣지 마십시오.
- 토큰을 바꾸면 `DESIGN.md`와 `registry.json`의 theme 항목을 같이 맞춰야 합니다 (`pnpm registry:sync`).
