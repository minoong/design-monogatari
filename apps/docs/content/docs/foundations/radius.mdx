입력은 `rounded-md`, 떠 있는 면은 `rounded-lg`, 누르는 알약은 `rounded-pill`입니다. 같은 화면에서도 역할이 바뀌면 라운딩도 바뀝니다.

<ComponentPreview name="radius/roles" />

## 토큰

<RadiusScale
  descriptions={{
    'rounded-md': '필드, 셀렉트, 아이콘 버튼',
    'rounded-lg': '카드, 다이얼로그, 버튼 기본값',
    'rounded-pill': '알약 모양 버튼',
  }}
/>

## 사용법

```tsx
<input className="rounded-md" />
<div className="rounded-lg border border-border" />
<button className="rounded-pill" />
```

값은 `@theme`의 `--radius-md`, `--radius-lg`, `--radius-pill`입니다. `Button`과 `IconButton`은 `radius` prop으로 같은 세 값을 고릅니다.

<Callout type="info" title="이 문서 사이트의 크롬은 다릅니다">
  문서 사이트의 사이드바와 메뉴는 Fumadocs의 기본 반경(6px, 8px)을 씁니다. 미리보기 영역 안의
  컴포넌트만 위 토큰 값 그대로 보입니다.
</Callout>
