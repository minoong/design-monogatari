움직임은 장식이 아니라 **상태가 바뀌었다는 알림**입니다. 선택하면 반응하고, 목록이 나타나고, 단계가 이동하는 것을 같은 시간과 곡선으로 보여 줍니다. 값은 `@repo/ui/motion`에 한 곳으로 모아 두었습니다.

<ComponentPreview name="motion/tokens" />

## 시간

| 토큰               | 값    | 쓰임                           |
| ------------------ | ----- | ------------------------------ |
| `DURATION.instant` | 0.12s | 감소 모션, 눈에 띄지 않는 전환 |
| `DURATION.fast`    | 0.18s | 호버, 눌림 같은 즉각 반응      |
| `DURATION.base`    | 0.28s | 선택, 상태 변화                |
| `DURATION.slow`    | 0.45s | 목록, 섹션 진입                |
| `DURATION.hero`    | 0.8s  | 화면당 한 번의 큰 연출         |

## 곡선과 스프링

| 토큰            | 값                               | 쓰임                                                      |
| --------------- | -------------------------------- | --------------------------------------------------------- |
| `EASE.outExpo`  | `cubic-bezier(0.22, 1, 0.36, 1)` | 진입과 선택 반응의 기본 (`ease-out-expo`)                 |
| `EASE.inOut`    | `cubic-bezier(0.65, 0, 0.35, 1)` | 크기·위치가 오가는 전환                                   |
| `SPRING.snappy` | stiffness 520, damping 32        | 눌림, 알림이 제자리로 돌아올 때                           |
| `SPRING.gentle` | stiffness 260, damping 28        | 패널과 카드 이동                                          |
| `SPRING.settle` | stiffness 460, damping 40        | 선택·단계 표시가 항목 사이를 옮겨 갈 때. 넘치지 않고 멈춤 |
| `SPRING.sheet`  | stiffness 420, damping 38        | 시트를 끌었다 놓은 뒤 제자리나 정해 둔 높이로 돌아올 때   |
| `SPRING.bouncy` | stiffness 380, damping 18        | 선택 확정 같은 작은 강조                                  |
| `STAGGER.base`  | 0.04s                            | 목록 항목 사이 지연                                       |

## 이미 적용된 곳

- **선택 반응**: `Radio`, `OptionRow`, `PackageRow`, `ColorSwatchGroup`은 선택되는 순간 표시가 0.6배에서 1.12배를 거쳐 1배로 돌아오고(`animate-select-pop`, 0.32초), 해제되면 커지지 않고 바로 0.6배로 줄어들며 사라집니다(`animate-select-out`, 0.2초). 처음 그려질 때는 움직이지 않습니다. 바뀐 순간은 `useCheckPhase` 훅이 알려 주며, 제어·비제어 모두 동작합니다. `Radio`와 `Checkbox` 단독은 자식을 둘 수 없는 `<input>`이라 `::before`에 그린 선택된 모습이 줄어들며 사라집니다. 입력 자체의 `box-shadow`와 `border`는 애니메이션하지 않습니다. 끝난 뒤에도 값이 유지되어 포커스 링과 오류 표시를 덮어쓰기 때문입니다.
- **단계 이동**: [`Stepper`](/docs/components/stepper)의 현재 단계 알약이 이전 단계에서 새 단계로 넘치지 않고 미끄러집니다(`SPRING.settle`).
- **선택 표시 이동**: [`Segmented`](/docs/components/segmented)는 선택 표시(알약, 밑줄, 링)가 이전 항목에서 새 항목으로 넘치지 않고 미끄러집니다(`SPRING.settle`). `snappy`는 이동 거리의 약 4.5%를 넘쳤다 돌아와서 따로 두었습니다.
- **옵션 선택 테두리**: [`OptionRow`](/docs/components/option-row)는 `OptionGroup` 안에서 선택 테두리가 이전 행에서 새 행으로 넘치지 않고 미끄러집니다(`SPRING.settle`). 선택하는 순간의 작은 튀어 오름(`animate-select-pop`)은 그대로입니다.
- **색 칩 선택 링**: [`ColorSwatchGroup`](/docs/components/color-swatch-group)의 선택 링은 요소 하나가 칩 사이를 줄과 소제목을 가로질러 넘치지 않고 미끄러집니다(`SPRING.settle`).
- **스위치 손잡이**: [`Switch`](/docs/components/switch)는 누르는 동안 손잡이가 16px에서 20px로 늘어났다가 놓으면 돌아오고, 켜고 끄면 손잡이가 280ms 동안 미끄러집니다(`ease-out-expo`, 넘치지 않음). 모두 CSS이고 감소 모션이면 바로 바뀝니다.
- **담기고 빠지는 컨트롤**: [`Presence`](/docs/components/presence)는 조건에 따라 있고 없는 컨트롤의 자리를 폭(또는 높이)으로 열고 닫아서 이웃이 한꺼번에 밀리지 않고 부드럽게 비켜 줍니다. `reserve`는 자리를 늘 잡아 두어 이웃이 전혀 움직이지 않고, 나머지(`collapse`, 기본 `slide`, `spring`)는 컨트롤이 자기 자리 안에서 잘리며 옆에서 밀려들고 밀려납니다(들어올 때 0.28초 `outExpo`, 나갈 때 0.28초 `inOut`). 투명도는 바꾸지 않아 반투명한 중간 상태가 없고, 처음부터 있던 것은 움직이지 않습니다. (아래 규칙 2의 예외).
- **시트**: [`Sheet`](/docs/components/sheet)는 투명도 없이 화면 가장자리까지 미끄러져 들어오고 나가며, 뒤 배경의 짙기는 시트의 위치에서 계산합니다(내리는 만큼 옅어집니다). 시트 위에 시트를 또 열면 바깥 시트가 안쪽 시트가 열린 정도에 따라 최대 5%까지 줄어듭니다.
- **알림 밀어 닫기**: [`Toast`](/docs/components/toast)는 터치와 펜으로 옆으로 밀어 닫을 수 있고, 닫히지 않으면 `SPRING.snappy`로 돌아옵니다. 마우스로는 밀리지 않습니다.
- **글자 바꾸기**: [`TextRoll`](/docs/components/text-roll)은 이전 글자가 밀려 나가고 새 글자가 같은 거리를 따라 들어옵니다(`DURATION.base`, `EASE.outExpo`).
- **한 자리에서 내용이 바뀔 때**: [`Morph`](/docs/components/morph)는 같은 자리를 번갈아 쓰는 내용(차량 위 모서리의 선루프 스위치와 안쪽 시점 안내)이 바뀔 때, 틀이 새 내용의 크기와 모서리로 스프링(`SPRING.settle`)을 따라 변형되고 내용은 틀 안에서 옆으로 밀려 바뀝니다. 투명도는 바꾸지 않습니다(아래 규칙 2의 예외).
- **펼침**: [`PackageRow`](/docs/components/package-row)의 구성 보기는 내용 높이까지 0.28초 동안 열리고 0.2초 동안 닫힙니다(아래 규칙 2의 예외).
- **목록 진입**: [`Reveal`](/docs/components/reveal)이 화면에 들어올 때 차례로 떠오릅니다.
- **눌림**: `Button`은 `SPRING.snappy`로 눌립니다.

## 규칙

1. **움직임은 상태 변화에 붙입니다.** 선택, 진입, 이동, 로딩입니다. 아무 일도 없을 때 계속 움직이는 장식(배경, 커서 따라다니기)은 쓰지 않습니다.
2. **`opacity`와 `transform`만 움직입니다.** 너비, 높이, 위치(`top`/`left`)를 애니메이션하면 레이아웃이 밀립니다. 예외는 두 곳입니다. `PackageRow`의 구성 보기는 Radix가 잰 높이(`--radix-accordion-content-height`)까지만 열리는 작은 목록이라 허용했고, `OptionGroup`의 선택 테두리는 절대 위치의 장식이라 높이를 움직여도 다른 요소의 배치가 밀리지 않습니다. `Morph`는 틀의 크기를 Motion의 `layout`으로 바꿔 옮기는 작은 틀 하나에 한정합니다. `Presence`는 컨트롤 하나가 담기고 빠질 때 이웃이 한꺼번에 밀리지 않고 부드럽게 비켜 주도록 폭(또는 높이)을 움직이며, 작은 컨트롤 하나에 한정합니다. 다른 곳에 높이 애니메이션이 필요해 보이면 먼저 예외로 둘 만한지 따져 보십시오.
3. **화면당 큰 연출은 하나입니다.** `DURATION.hero`와 `SPRING.bouncy`는 한 화면에 한 번만 씁니다.
4. **감소 모션을 기본으로 지킵니다.** `useReducedMotion()`으로 읽고, 이동은 없애고 짧은 페이드(`DURATION.instant`)만 남깁니다. 설정이 바뀌면 바로 반영되도록 마운트 때 한 번만 읽지 않습니다. CSS 애니메이션은 `motion-safe:`로 감싸서 감소 모션에서는 아예 적용하지 않습니다(`motion-reduce:animate-none`은 `peer-checked:` 같은 변형에 특이도에서 져서 꺼지지 않습니다).
5. **Motion과 Tailwind `transition-*`을 같은 요소에 쓰지 않습니다.** WebGL 캔버스에는 Motion을 쓰지 않습니다.
6. **화면 밖에서는 멈춥니다.** 뷰포트 밖이거나 탭이 숨겨진 동안은 계속 도는 애니메이션이 없어야 합니다.

## 사용법

```tsx
import { motion } from 'motion/react';

import { DURATION, EASE, SPRING } from '@/lib/motion';

<motion.div
  initial={{ opacity: 0, y: 12 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: DURATION.slow, ease: EASE.outExpo }}
/>;

<motion.button whileTap={{ scale: 0.96 }} transition={SPRING.snappy} />;
```

CSS만으로 되는 짧은 반응은 `animate-select-pop`처럼 테마에 정의된 키프레임을 쓰십시오.
