두께는 Tailwind의 `border`(1px), 색은 `--border` 토큰, 포커스는 `ring-ring`이에요. 카드, 입력, 다이얼로그, 보조 버튼이 같은 헤어라인을 나눠 써요.

<ComponentPreview name="border/hairline" />

## 사용법

```tsx
<div className="border-border rounded-lg border" />
<input className="border-border focus-visible:ring-ring border focus-visible:ring-2" />
```

## 구분선

목록이나 표는 `border-b border-border`로 나눠 주세요. 마지막 줄에는 `last:border-b-0`을 붙이면 바깥 테두리와 겹치지 않아요.

## 지켜 주세요

- 5~8% 검정은 흰 배경에서, 5~8% 흰색은 검정 배경에서 사라져요. 쓰지 마세요.
- 선택된 항목 강조는 `border-primary`, 포커스는 `ring-2 ring-ring`이에요. 포커스 링과 `border-primary`를 섞지 마세요.
- 오류 필드는 `aria-invalid`를 켜서 `destructive`로 바뀌게 하세요. `primary`로 칠하지 않아요.
