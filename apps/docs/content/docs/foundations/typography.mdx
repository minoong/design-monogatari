폰트는 Geist입니다. 앱이 아닌 환경(Storybook 등)에서는 `system-ui`로 떨어집니다. SF Pro는 웹폰트로 쓰지 않습니다. 크기를 외우지 말고 역할에 맞는 클래스만 고르십시오.

<ComponentPreview name="typography/scale" />

## 역할 토큰

<TypeScale />

`text-[17px]`이나 `text-[28px]`처럼 값을 직접 적지 마십시오. 폼 컨트롤은 캡션과 같은 14px인 `text-sm`을 써도 됩니다.

## 사용법

```tsx
<h1 className="font-sans text-title font-semibold tracking-tight">제목</h1>
<p className="font-sans text-body">본문</p>
<p className="text-muted-foreground text-caption">도움말</p>
```

## 지켜 주십시오

- 제목은 굵기 600에 `tracking-tight`입니다. 700이 아닙니다.
- 본문은 400, 강조는 600입니다.
- 폰트 패밀리는 `font-sans`와 `font-mono`로 고르십시오. 값은 `@theme`의 `--font-sans`, `--font-mono`입니다.
