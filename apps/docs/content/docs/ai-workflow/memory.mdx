Claude Code는 시작할 때와 파일을 열 때 지침 파일을 컨텍스트에 올립니다. 지침은 **컨텍스트이지 강제가 아닙니다.** 그래서 이 저장소는 지침을 짧게 유지하고, 지켜져야 하는 것은 [훅](/docs/ai-workflow/hooks)이나 `pnpm verify`로 옮깁니다.

## 구성

| 파일                                       | 불러오는 때                                    | 내용                                          |
| ------------------------------------------ | ---------------------------------------------- | --------------------------------------------- |
| `CLAUDE.md` (루트)                         | 항상                                           | 명령, 아키텍처, 쉽게 어기는 규칙, 작업 순서   |
| `.claude/rules/*.md`                       | 항상 또는 `paths`에 맞는 파일을 열 때          | 주제별 규칙(디자인, 스타일, 모션, 도메인 등)  |
| `apps/*/CLAUDE.md`, `packages/*/CLAUDE.md` | 그 폴더 작업 때                                | 폴더별 `AGENTS.md`를 가져옵니다(`@AGENTS.md`) |
| `AGENTS.md`                                | 루트 `CLAUDE.md`가 있으면 자동으로는 읽지 않음 | 다른 도구와 사람을 위한 색인과 폴더 설명      |

루트에 `CLAUDE.md`가 있으면 Claude Code는 루트 `AGENTS.md`를 읽지 않습니다. 그래서 필요한 내용은 `CLAUDE.md`와 `.claude/`에 둡니다. 폴더 안의 `CLAUDE.md`는 한 줄(`@AGENTS.md`)로 그 폴더의 `AGENTS.md`를 가져옵니다.

## 규칙은 18개이고, 항상 켜진 것은 5개입니다

항상 켜진 규칙은 `agent-loop`, `code-quality`, `git-workflow`, `pnpm-monorepo`, `stack-guardrails`입니다. 나머지는 `paths`로 한정해서, 해당 파일을 읽거나 고칠 때만 불러옵니다.

<RepoFile path=".claude/rules/estimate-domain.md" lines="1-10" />

예를 들어 견적 도메인 규칙은 `apps/web/src/**/estimate/**`를 다룰 때만 올라옵니다. 이렇게 하면 모든 대화에서 모든 규칙을 읽느라 컨텍스트를 쓰지 않습니다.

## 어떤 지침이 언제 올라왔는지 기록합니다

`InstructionsLoaded` 훅이 지침 파일이 언제, 왜(세션 시작, 하위 폴더 탐색, 경로 일치, 포함, 압축) 올라왔는지를 로그에 남깁니다. 프로젝트 안의 상대 경로만 남기고 사용자 홈의 파일은 경로를 버립니다. 실제 로그에서 경로 일치(`path_glob_match`)로 올라온 기록이 가장 많았고, 이는 경로 한정 규칙이 설계대로 동작한다는 증거입니다. 자세한 수치는 [개선 기록](/docs/ai-workflow/retrospective)에 있습니다.

## 개인 메모리

저장소 밖에 있는 개인 메모리에는 작업 방식에 대한 피드백이 남습니다. 커밋 메시지는 배경, 이유, 검증, 한계를 문단으로 쓴다, 문구는 합쇼체로 쓰고 은행 예시를 쓰지 않는다, 모션은 수치로 확인한다, PR은 한 번에 하나씩 올린다 같은 것입니다. 저장소에 이미 적힌 내용(코드 구조, 과거 수정)은 메모리에 중복해서 저장하지 않습니다.

서브에이전트 중 `a11y-reviewer`와 `design-reviewer`는 `memory: project`를 켜서, 이 저장소에서 반복되는 문제를 `.claude/agent-memory/`에 한 줄씩 기록하고 다음 리뷰 전에 읽습니다. 이 폴더는 저장소에 포함됩니다.
