## 사용법

```tsx
import { OptionGroup, OptionRow } from '@/components/ui/option-row';

export function Example() {
  const [value, setValue] = useState('w19');

  return (
    <OptionGroup legend="휠">
      <OptionRow
        name="wheel"
        value="w19"
        label="19인치 기본 휠"
        price="기본 포함"
        checked={value === 'w19'}
        onChange={() => setValue('w19')}
      />
      <OptionRow
        name="wheel"
        value="w20"
        label="20인치 알로이 휠"
        price="+1,500,000원"
        checked={value === 'w20'}
        onChange={() => setValue('w20')}
      />
    </OptionGroup>
  );
}
```

같은 `name`을 가진 `OptionRow`를 `OptionGroup`(`fieldset` + `legend`) 안에 놓습니다. 가격 문구의 형식은 호출하는 쪽이 정합니다. 색을 칩으로 고르는 자리는 [`ColorSwatchGroup`](/docs/components/color-swatch-group), 여러 개를 켜고 끄는 자리는 [`PackageRow`](/docs/components/package-row)를 쓰십시오.

## 예시

### 선택할 수 없는 옵션

`unavailableReason`을 주면 행이 `muted` 면으로 바뀌고 이유가 행 안에 항상 보입니다. 마우스를 올려야만 보이는 툴팁에 기대지 않습니다.

이때 입력은 비활성이 **아닙니다**. 눌러 보면 `onChange`가 호출되니, 호출하는 쪽에서 "스포트 트림으로 변경하시겠습니까?" 같은 대안을 안내할 수 있습니다. 아예 막고 싶다면 `disabled`를 쓰십시오(키보드로도 들어가지 못합니다).

<Callout type="warn" title="방향키로 훑을 때도 onChange가 호출됩니다">
  라디오는 방향키로 옮겨 갈 때도 선택이 바뀝니다. 선택 불가 행에서 호출되는 `onChange`에서 모달을
  열거나 포커스를 옮기면 키보드 사용자가 그룹을 지나가기만 해도 끼어듭니다. 모달은 클릭이나 Enter
  같은 명시적 동작에서 열고, `onChange`에서는 안내 문구를 보여 주는 정도로 두십시오.
</Callout>

`<input>`의 모든 속성과 `ref`를 받습니다(`type`은 `radio`로 고정입니다). 직접 정의한 props는 아래와 같습니다.

    description: '스펙 한 줄 같은 보조 설명입니다. aria-describedby로 연결됩니다.',
    price: '화면에 보일 가격 문구입니다. 포맷은 호출하는 쪽이 정합니다.',
    media: '썸네일이나 아이콘입니다.',
    badge: '이름 옆에 붙는 작은 표식입니다.',
    unavailableReason:
      '지금 고를 수 없는 이유입니다. 행에 항상 보이고 입력은 활성 상태로 남습니다.',
  }}
/>

`OptionGroup`은 `fieldset`의 모든 속성과 `legend`(그룹 이름)를 받습니다.

## 접근성

- 네이티브 라디오(시각적으로만 숨김)라서 같은 `name`끼리 방향키로 이동하고 선택 상태를 브라우저가 알려 줍니다.
- 이름은 `aria-labelledby`로, 설명·가격·선택 불가 이유는 `aria-describedby`로 입력에 연결됩니다. `unavailableReason`이 있으면 `aria-disabled`가 켜집니다. 스크린 리더마다 읽는 말은 다르지만(비활성, 사용 불가 등) 이유는 설명으로 함께 읽힙니다. 이 상태에서도 Tab 정지는 그룹당 하나입니다.
- 선택은 테두리 색과 1px 추가 링으로, 포커스는 2px 아웃라인(간격 2px)으로 보입니다. 둘은 서로 다른 표시라 함께 있어도 구분됩니다. `OptionGroup` 안에서는 이 선택 테두리가 하나의 요소로 행 사이를 넘치지 않고 미끄러집니다(`SPRING.settle`). 감소 모션이면 바로 옮겨 가고, 강제 색상 모드에서는 `Highlight` 테두리로 남습니다. 묶음 밖의 행은 CSS로 그려서 미끄러지지 않습니다.
- 선택되면 표시가 0.32초 튀어 오르고, 같은 묶음에서 다른 행이 선택되면 이전 행의 선택 표시가 바로 줄어들며 사라집니다. 제어 컴포넌트와 비제어 모두 동작합니다. 처음 그려질 때는 움직이지 않으며 감소 모션이면 꺼집니다.
- 눌림이나 호버에 크기 변화가 없고, 색 전환은 `prefers-reduced-motion`에서 꺼집니다.
- 선택 불가 행의 글자색은 `muted-foreground`입니다. 이유 문구는 `foreground`를 써서 읽기 쉽게 했습니다.
