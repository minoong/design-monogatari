## 사용법

```tsx
import { OptionGroup, OptionRow } from '@/components/ui/option-row';

export function Example() {
  const [value, setValue] = useState('w19');

  return (
    <OptionGroup legend="휠">
      <OptionRow
        name="wheel"
        value="w19"
        label="19인치 기본 휠"
        price="기본 포함"
        checked={value === 'w19'}
        onChange={() => setValue('w19')}
      />
      <OptionRow
        name="wheel"
        value="w20"
        label="20인치 알로이 휠"
        price="+1,500,000원"
        checked={value === 'w20'}
        onChange={() => setValue('w20')}
      />
    </OptionGroup>
  );
}
```

같은 `name`을 가진 `OptionRow`를 `OptionGroup`(`fieldset` + `legend`) 안에 놓아요. 가격 문구의 형식은 호출하는 쪽이 정해요. 색을 칩으로 고르는 자리는 [`ColorSwatchGroup`](/docs/components/color-swatch-group), 여러 개를 켜고 끄는 자리는 [`PackageRow`](/docs/components/package-row)를 쓰세요.

## 예시

### 선택할 수 없는 옵션

`unavailableReason`을 주면 행이 `muted` 면으로 바뀌고 이유가 행 안에 항상 보여요. 마우스를 올려야만 보이는 툴팁에 기대지 않아요.

이때 입력은 비활성이 **아니에요**. 눌러 보면 `onChange`가 호출되니, 호출하는 쪽에서 "스포트 트림으로 바꿀까요?" 같은 대안을 안내할 수 있어요. 아예 막고 싶다면 `disabled`를 쓰세요(키보드로도 들어가지 못해요).

<Callout type="warn" title="방향키로 훑을 때도 onChange가 호출돼요">
  라디오는 방향키로 옮겨 갈 때도 선택이 바뀌어요. 선택 불가 행에서 호출되는 `onChange`에서 모달을
  열거나 포커스를 옮기면 키보드 사용자가 그룹을 지나가기만 해도 끼어들어요. 모달은 클릭이나 Enter
  같은 명시적 동작에서 열고, `onChange`에서는 안내 문구를 보여 주는 정도로 두세요.
</Callout>

## API 레퍼런스

`<input>`의 모든 속성과 `ref`를 받아요(`type`은 `radio`로 고정이에요). 직접 정의한 props는 아래와 같아요.

<PropsTable
  file="packages/ui/src/option-row.tsx"
  name="OptionRowProps"
  include={['label', 'description', 'price', 'media', 'badge', 'unavailableReason']}
  descriptions={{
    label: '옵션 이름이에요. 입력의 접근성 이름(aria-labelledby)이 돼요.',
    description: '스펙 한 줄 같은 보조 설명이에요. aria-describedby로 연결돼요.',
    price: '화면에 보일 가격 문구예요. 포맷은 호출하는 쪽이 정해요.',
    media: '썸네일이나 아이콘이에요.',
    badge: '이름 옆에 붙는 작은 표식이에요.',
    unavailableReason: '지금 고를 수 없는 이유예요. 행에 항상 보이고 입력은 활성 상태로 남아요.',
  }}
/>

`OptionGroup`은 `fieldset`의 모든 속성과 `legend`(그룹 이름)를 받아요.

## 접근성

- 네이티브 라디오(시각적으로만 숨김)라서 같은 `name`끼리 방향키로 이동하고 선택 상태를 브라우저가 알려 줘요.
- 이름은 `aria-labelledby`로, 설명·가격·선택 불가 이유는 `aria-describedby`로 입력에 연결돼요. `unavailableReason`이 있으면 `aria-disabled`가 켜져요. 스크린 리더마다 읽는 말은 다르지만(비활성, 사용 불가 등) 이유는 설명으로 함께 읽혀요. 이 상태에서도 Tab 정지는 그룹당 하나예요.
- 선택은 테두리 색과 1px 추가 링으로, 포커스는 2px 아웃라인(간격 2px)으로 보여요. 둘은 서로 다른 표시라 함께 있어도 구분돼요.
- 눌림이나 호버에 크기 변화가 없고, 색 전환은 `prefers-reduced-motion`에서 꺼져요.
- 선택 불가 행의 글자색은 `muted-foreground`예요. 이유 문구는 `foreground`를 써서 읽기 쉽게 했어요.
