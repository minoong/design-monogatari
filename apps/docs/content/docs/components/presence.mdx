## 사용법

```tsx
import { Presence } from '@/components/ui/presence';
import { Switch } from '@/components/ui/switch';

export function Example({ hasSunroof }: { hasSunroof: boolean }) {
  return (
    <Presence show={hasSunroof}>
      <Switch aria-label="선루프 열어 보기" />
    </Presence>
  );
}
```

옵션을 담거나 빼면 나타났다 사라지는 컨트롤처럼, 조건에 따라 있고 없는 요소를 감쌉니다. 그냥 조건부로 그리면 컨트롤이 끼어드는 순간 옆 컨트롤이 한꺼번에 밀리고, 빠지는 순간 한꺼번에 당겨집니다. `Presence`는 컨트롤이 차지하는 자리를 폭(또는 높이)으로 열고 닫아서, 이웃이 그만큼 부드럽게 비켜 줍니다. 투명도는 바꾸지 않습니다. 서서히 진해지거나 옅어지는 반투명한 중간 상태 없이, 항상 또렷한 채로 드러납니다. 들어올 때 0.28초(`outExpo`), 나갈 때 0.28초(`inOut`)이고(`spring`은 스프링), 나가는 움직임이 끝난 뒤에 DOM에서 내려갑니다(`reserve`는 DOM에 남습니다).

이웃과의 간격은 flex `gap`이 아니라 컨트롤의 마진(`mx-2` 등)으로 주십시오. 마진은 `Presence` 안에 있어 자리와 함께 열리고 닫히지만, `gap`은 컨트롤이 DOM에서 내려가는 순간 그 간격만큼 한 번에 튑니다.

폭이나 높이를 움직이는 예외입니다. 모션 문서의 "`opacity`와 `transform`만 움직인다"는 규칙은 보통 레이아웃이 밀리는 것을 막으려는 것인데, 여기서는 이웃이 부드럽게 비켜 주는 것이 목적이라 허용했습니다. 작은 컨트롤 하나에 쓰고, 큰 영역에는 쓰지 마십시오.

## 예시

### 세 가지 모양

`variant`로 고릅니다. 이웃 버튼을 양옆에 두고 같은 컨트롤을 담고 빼 보십시오.

<ComponentPreview name="presence/compare" />

- `collapse`: 자리가 열리고 닫히며 컨트롤이 그 자리에서 드러납니다. 컨트롤은 제자리에 있고 자리를 감싼 틀만 움직입니다.
- `slide`(기본): `collapse`에 더해 컨트롤이 `from` 쪽에서 밀려들고 그쪽으로 밀려납니다. 자기 자리 안에서 잘려서 이웃 위를 지나지 않습니다.
- `spring`: `slide`와 같은 움직임을 시간 곡선 대신 스프링(`SPRING.settle`)으로 합니다. 넘치지 않고 멈추며, 시간은 정해져 있지 않습니다.
- `reserve`: 자리는 늘 잡아 두고 컨트롤만 그 안에서 밀려들고 나갑니다. 이웃이 전혀 움직이지 않으므로 덜컹거림이 없습니다. 꺼져 있는 동안 그 자리는 빈 채로 남으니, 줄의 끝처럼 빈 자리가 거슬리지 않는 곳에 두십시오. 꺼진 동안에도 컨트롤은 DOM에 남아 있되 보이지 않고 `inert`입니다(안의 상태도 남습니다).

앞의 세 가지는 이웃이 프레임마다 밀리므로 줄이 덜컹거리는 느낌이 날 수 있습니다. 그것이 거슬리면 `reserve`를 쓰십시오. 움직임이 필요 없으면 이 컴포넌트를 쓰지 않고 조건부로 그리면 됩니다.

### 방향

`from`은 자리가 열리는 축과 밀려드는 쪽입니다(`left` 기본, `right`는 가로, `up`·`down`은 세로로 높이가 열리고 닫힙니다. `reserve`는 자리가 변하지 않고 밀려드는 쪽만 정합니다).

### 처음부터 있는 것

`show`가 처음부터 켜져 있으면 처음 그릴 때 움직이지 않습니다(화면을 열 때 갑자기 움직이지 않게). 처음에도 보이고 싶으면 `animateOnMount`를 켜십시오.

## 접근성

- 사라지는 동안에는 `inert`라서 포커스와 클릭을 받지 않고, 낭독기의 접근성 트리에서도 바로 빠집니다(0.28초 움직임을 기다리지 않습니다). 움직임이 끝나면 DOM에서 내려갑니다.
- `Presence` 안에 포커스가 있는 채로 `show`를 끄면 브라우저가 포커스를 `body`로 떨어뜨립니다(브라우저마다 다음 탭 위치도 다릅니다). 자기 자신을 빼는 버튼처럼 이런 경우가 있으면 `show`를 끄기 전에 호출하는 쪽이 포커스를 다른 곳으로 옮기십시오.
- `prefers-reduced-motion`이면 움직임 없이 바로 나타나고 사라집니다.
- 처음부터 켜져 있던 요소는 움직이지 않으므로, 화면을 열 때 갑자기 움직여서 방해하는 일이 없습니다.
- 나타나거나 사라질 때 낭독기에 따로 알리지 않습니다. 상태 변화를 꼭 알려야 하면 `aria-live` 영역에 따로 말해 주십시오.
