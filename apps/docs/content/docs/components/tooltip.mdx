## 사용법

앱 최상위를 `TooltipProvider`로 한 번 감싸 열림 지연을 정합니다. 트리거에는 `asChild`로 이미 있는 버튼을 넘깁니다.

```tsx
import { IconButton } from '@/components/ui/icon-button';
import { HeartIcon } from '@/components/ui/icons/heart';
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from '@/components/ui/tooltip';

export function Example() {
  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger asChild>
          <IconButton aria-label="관심 차량 담기">
            <HeartIcon />
          </IconButton>
        </TooltipTrigger>
        <TooltipContent>관심 차량 담기</TooltipContent>
      </Tooltip>
    </TooltipProvider>
  );
}
```

언제 쓰는가: 글자가 없는 아이콘 버튼의 이름, 비활성인 이유처럼 **없어도 일을 마칠 수 있는** 짧은 보조 설명입니다.

쓰지 않는 경우: 터치에서는 열리지 않으므로 꼭 알려야 하는 내용(가격, 제약, 오류)은 화면에 직접 보이십시오. 터치로 아이콘 버튼을 누르면 이름이 보이지 않으니, 중요한 컨트롤은 글자 이름을 함께 두십시오. 말풍선 안에 링크나 버튼을 넣지 마십시오. 아이콘 버튼의 이름은 `aria-label`로 따로 주십시오(툴팁은 이름을 대신하지 않습니다).

## 예시

### 방향

`side`로 열리는 방향을 정합니다. 화면 끝에서는 자리가 모자라면 반대쪽으로 뒤집힙니다.

### 비활성 버튼

비활성(`disabled`) 버튼은 포인터와 포커스를 받지 않아 트리거로 쓸 수 없습니다. 임시 방법으로, 버튼을 포커스를 받는 `span`(`tabIndex={0}`)으로 감싸 그 `span`을 트리거로 씁니다. 이 `span`에는 포커스 링을 직접 주고(아래 코드), 터치에서는 말풍선이 열리지 않으므로 이유를 버튼 아래에 글자로도 보이십시오. 코드 탭의 `eslint-disable` 주석은 접근성 린트가 이 패턴을 알려 주는 것입니다. `Button`이 `aria-disabled`를 지원하면 감싸는 `span` 없이 버튼 자체를 트리거로 쓸 수 있습니다(예정).

## API 레퍼런스

Radix [Tooltip](https://www.radix-ui.com/primitives/docs/components/tooltip)을 감쌌습니다. 아래는 이 시스템에서 기본값을 바꾼 것과 자주 쓰는 속성입니다.

### TooltipProvider

| 속성                      | 타입      | 기본값  | 설명                                                                                                    |
| ------------------------- | --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `delayDuration`           | `number`  | `400`   | 마우스를 올린 뒤 열리기까지의 시간(ms). `Tooltip`마다 따로 줄 수도 있습니다.                            |
| `skipDelayDuration`       | `number`  | `300`   | 하나가 닫힌 뒤 이 시간 안에 다른 툴팁에 올리면 지연 없이 바로 열립니다. 줄지은 버튼을 훑을 때 쓰입니다. |
| `disableHoverableContent` | `boolean` | `false` | `true`로 하면 말풍선 위로 마우스를 옮기면 닫힙니다. 기본은 옮겨도 열린 채 있습니다.                     |

### Tooltip, TooltipTrigger

`Tooltip`은 Radix `Tooltip.Root`입니다(`open`, `defaultOpen`, `onOpenChange`, `delayDuration`). `TooltipTrigger`는 `Tooltip.Trigger`이고 `asChild`로 이미 있는 버튼을 트리거로 씁니다.

### TooltipContent

Radix `Tooltip.Content`의 속성과 `ref`, `className`을 받고, 포털을 이미 감쌉니다.

| 속성               | 타입                                     | 기본값     | 설명                                                |
| ------------------ | ---------------------------------------- | ---------- | --------------------------------------------------- |
| `side`             | `"top" \| "right" \| "bottom" \| "left"` | `"top"`    | 열리는 방향. 자리가 모자라면 반대쪽으로 뒤집힙니다. |
| `sideOffset`       | `number`                                 | `6`        | 트리거와의 거리(px).                                |
| `align`            | `"start" \| "center" \| "end"`           | `"center"` | 트리거에 맞추는 위치.                               |
| `collisionPadding` | `number`                                 | `8`        | 화면 가장자리에서 띄울 거리(px).                    |

## 접근성

Radix 1.4.1의 소스를 읽어 확인한 동작입니다.

- 말풍선에는 `role="tooltip"`이 붙고, 트리거의 `aria-describedby`는 **열려 있는 동안에만** 말풍선과 이어집니다.
- 키보드 포커스가 들어오면 지연 없이 열리고, 포커스가 빠지면 닫힙니다. 마우스로 눌러서 들어온 포커스는 열지 않습니다. Esc는 열려 있을 때 닫고(마우스나 포커스를 옮기지 않아도), 트리거를 누르거나 클릭해도, 스크롤해도 닫힙니다. 말풍선 위로 마우스를 옮겨도 열린 채 있습니다(`disableHoverableContent`로 끌 수 있습니다).
- 마우스를 올리면 열리지만 터치에서 올라온 이벤트는 무시합니다. 터치로는 열 수 없으므로 중요한 정보를 말풍선에만 두지 마십시오.
- 아이콘 버튼의 `aria-label`은 그대로 두십시오(없으면 닫힌 버튼에 이름이 없습니다). 같은 문구를 말풍선에도 쓰면 열렸을 때 낭독기가 이름 뒤에 설명으로 한 번 더 읽을 수 있습니다(실제 낭독기에서는 확인하지 못했습니다). 말풍선은 마우스 사용자를 위한 눈에 보이는 사본으로 보고, 겹치는 읽기가 거슬리면 말풍선에 이름에 없는 정보(단축키, 짧은 힌트)를 더하십시오.
- 비활성 버튼은 위 예시처럼 포커스를 받는 `span`으로 감싸야 키보드로 열 수 있습니다. 이 `span`은 역할과 이름이 없고 열려 있는 동안에만 설명이 이어지므로, 이유를 화면에 글자로도 보이십시오. 낭독기에서 어떻게 읽히는지는 확인하지 못했습니다.
- 말풍선은 `foreground` 면에 `background` 글자의 반전색이라 대비가 본문과 같습니다(라이트·다크 모두). 고대비(forced-colors) 모드에서는 배경색이 지워지므로 테두리가 가장자리를 남깁니다.
- 열릴 때 트리거에 가까운 쪽 4px 떨어진 곳에서 제자리로 이동하며 나타나고(0.18초), 하나가 열린 직후 옆으로 옮겨 이어서 열릴 때는 움직임 없이 바로 보입니다. 감소 모션이면 이동 없이 투명도만 짧게 바뀝니다.
