## 사용법

```tsx
import { PackageRow } from '@/components/ui/package-row';

export function Example() {
  const [checked, setChecked] = useState(false);

  return (
    <PackageRow
      label="파퓰러 패키지"
      price="+3,600,000원"
      items={['드라이빙 어시스턴스', '헤드업 디스플레이']}
      checked={checked}
      onChange={(event) => setChecked(event.target.checked)}
    />
  );
}
```

하나만 고르는 자리는 [`OptionRow`](/docs/components/option-row)를 쓰십시오. `items`를 주면 "구성 보기" 버튼이 생기고, 주지 않으면 체크박스 한 줄만 그립니다.

## 예시

### 다른 패키지에 포함된 항목

`includedIn`을 주면 행이 `muted` 면이 되고 "파퓰러 패키지에 포함" 같은 표식이 붙습니다. 체크박스를 막지는 않습니다. 눌러서 해제하면 패키지를 풀어야 하니, 호출하는 쪽에서 확인 안내를 띄우고 상태를 바꾸십시오.

## 접근성

- 네이티브 체크박스(시각적으로만 숨김)라서 스페이스로 켜고 끄고 상태를 브라우저가 알려 줍니다. 이름은 `aria-labelledby`, 설명은 `aria-describedby`로 연결됩니다.
- 가격은 `aria-describedby`로 연결됩니다.
- 체크하면 체크 표시가 0.32초 튀어 오르고, 해제하면 채움이 0.2초 동안 줄어들며 사라집니다. 처음 그려질 때는 움직이지 않으며 감소 모션이면 둘 다 꺼집니다.
- 펼침은 Radix Accordion입니다. 버튼은 Enter와 스페이스로 열고 닫고, `aria-expanded`와 `aria-controls`가 자동으로 붙습니다. 펼친 목록은 `region`이고 이름은 펼침 버튼의 이름을 따릅니다.
- 펼침 버튼의 이름은 "구성 보기"에 패키지 이름을 이어 붙여서, 여러 행이 있어도 어느 패키지인지 구분됩니다.
- 체크 표시는 체크 모양 아이콘과 테두리 색이 함께 바뀝니다.
- 화살표 회전은 `prefers-reduced-motion`에서 꺼집니다. 펼침 자체에는 높이 애니메이션이 없습니다.
