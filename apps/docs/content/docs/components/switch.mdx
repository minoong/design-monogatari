## 사용법

```tsx
import { Label } from '@/components/ui/label';
import { Switch } from '@/components/ui/switch';

export function Example() {
  return (
    <div className="flex items-center gap-3">
      <Switch id="alerts" defaultChecked />
      <Label htmlFor="alerts">견적 알림 받기</Label>
    </div>
  );
}
```

바로 켜고 끄면 효과가 나는 한 가지 설정(알림, 테마 미리 보기)에 씁니다. 여러 항목 중 몇 개를 고르는 선택은 [`Checkbox`](/docs/components/checkbox)나 [`PackageRow`](/docs/components/package-row)를, 하나만 고르는 선택은 [`OptionRow`](/docs/components/option-row)나 [`Segmented`](/docs/components/segmented)를 쓰십시오. 폼에서 "제출해야 반영되는" 값이라면 스위치보다 체크박스가 맞습니다.

속은 네이티브 체크박스라서 `checked`와 `onChange`로 제어하거나 `defaultChecked`로 비제어로 쓰고, `name`과 `value`를 주면 폼으로 전송됩니다. 꺼진 스위치는 값이 전송되지 않고, 켜진 스위치만 `name=value`(`value`를 안 주면 `on`)로 갑니다. 이름표는 [`Label`](/docs/components/label)을 `htmlFor`로 이어 주거나, 이름표가 없으면 `aria-label`을 주십시오.

## 예시

### 비활성과 오류

`disabled`는 회색으로 바뀌고 누를 수 없습니다. 꺼짐과 켜짐 모두 손잡이의 위치와 트랙의 채움이 달라서 상태를 알 수 있고, 이름표 글자도 `text-muted-foreground`로 함께 낮춰 주십시오. 오류는 `aria-invalid`로 알리고 `destructive` 링이 둘러집니다.

## API 레퍼런스

`Switch`는 `<input>`의 속성을 받습니다. `type`과 `role`은 고정되어 있어 바꿀 수 없습니다.

## 접근성

- `input[type=checkbox]`에 `role="switch"`가 붙어 스크린 리더가 "스위치, 켜짐" 또는 "꺼짐"으로 읽습니다. 스페이스로 켜고 끄고, Tab으로 이동합니다. 이름은 `Label`이나 `aria-label`로 꼭 주십시오.
- 켜짐과 꺼짐은 색만이 아니라 손잡이의 위치로도 구분됩니다. 꺼짐은 연한 트랙과 헤어라인 테두리(`Checkbox`와 `Radio`의 안 켜진 상태와 같습니다)에 회색 손잡이가 왼쪽, 켜짐은 파란 트랙에 손잡이가 오른쪽입니다. 손잡이(`muted-foreground`)는 트랙과 4.66:1 이상 대비되고, 상태는 색뿐 아니라 손잡이의 위치로 알립니다.
- 눈에 보이는 트랙은 44×24px이고, 투명한 `::before`가 위아래로 6px씩 넓혀 누를 수 있는 영역이 세로 36px입니다. 더 넓히면 `gap-3`(12px)로 쌓은 이웃 스위치의 클릭을 가로채서 이 크기로 멈췄습니다. 연결된 `Label`을 눌러도 켜지고 꺼지므로 이름표를 꼭 이어 주십시오.
- 누르는 동안 손잡이가 16px에서 20px로 늘어납니다. 마우스, 스페이스, 연결된 `Label`을 누를 때 입력이 `:active`가 되어 같은 효과가 나고 놓으면 돌아옵니다. 터치는 기기에 따라 늘어나지 않을 수 있습니다(확인하지 못했습니다). 켜고 끌 때 손잡이는 280ms 동안 미끄러지고 트랙 색도 함께 바뀝니다. `prefers-reduced-motion`이면 늘어나지도 미끄러지지도 않고 바로 바뀝니다.
- 키보드 포커스는 2px 링(간격 2px)으로 보입니다.
- 윈도 고대비 같은 강제 색상 모드에서는 배경이 지워지므로 트랙 테두리가 `ButtonText`로, 켜짐은 `Highlight` 채움과 `HighlightText` 손잡이로 남습니다.
- 비활성은 `disabled`의 기본 동작(포커스와 입력 불가)을 따릅니다. 강제 색상 모드에서는 `GrayText`로 남습니다.
- 오류(`aria-invalid`)는 링으로 알리는데 강제 색상 모드에서는 링이 지워집니다. 오류 설명 글을 함께 두십시오.
