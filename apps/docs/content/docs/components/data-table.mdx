## 사용법

```tsx
import { DataTable, type DataTableColumn } from '@/components/ui/data-table';

type Fee = { region: string; delivery: number };

const columns: DataTableColumn<Fee>[] = [
  { key: 'region', header: '탁송 지역', rowHeader: true },
  { key: 'delivery', header: '탁송료', numeric: true, cell: (row) => `${row.delivery}원` },
];

export function Example({ fees }: { fees: Fee[] }) {
  return (
    <DataTable
      caption="지역별 탁송료"
      columns={columns}
      rows={fees}
      getRowKey={(row) => row.region}
    />
  );
}
```

열은 `columns`로, 행은 `rows`로 넘깁니다. 금액이나 서식이 필요한 칸은 `cell`로 직접 그리고, 가격 형식은 호출하는 쪽이 정합니다. 두 열짜리 변경 비교는 [`ChangeDiff`](/docs/components/change-diff)를 쓰십시오.

## 접근성

- 시맨틱 `table`입니다. `caption`이 표의 이름이고, 열 제목은 `scope="col"`, `rowHeader` 열은 `scope="row"`라서 표 탐색 모드에서 셀마다 행과 열 이름이 함께 읽힙니다(읽는 방식은 스크린 리더에 따라 다릅니다). `captionHidden`일 때는 숨겨진 `caption`이 이름으로 잡히지 않는 브라우저를 위해 표에도 `aria-labelledby`를 답니다.
- 금액 열은 오른쪽에 맞추고 `tabular-nums`로 자릿수를 가지런히 합니다.
- 표 바깥 `div`는 `role="region"`이고 이름은 표 이름입니다. 좁은 화면에서 표가 넘치면 가로로 스크롤되는데, 이 영역이 키보드 초점(`tabIndex=0`)을 받으므로 방향키로 스크롤할 수 있습니다. 숫자 칸은 줄바꿈하지 않아 금액이 중간에서 끊기지 않고, 글자 칸은 줄바꿈됩니다. 한 화면에 표가 여럿이면 `caption`을 서로 다르게 쓰십시오.
- 합계 줄은 `tfoot`입니다. 합계 줄에 `rowHeader` 열의 값(예: "합계")을 반드시 주십시오. 값이 없으면 그 칸은 이름 없는 행 제목이 되지 않도록 일반 칸으로 그려집니다.
- 아이콘만 있는 열은 `header`에 `sr-only` 글자를 넣어 열 이름을 알리십시오.
