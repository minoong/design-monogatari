## 사용법

```tsx
import { ChangeDiff } from '@/components/ui/change-diff';

export function Example() {
  return (
    <ChangeDiff
      rows={[
        { label: '휠', before: '20인치 알로이 휠', after: '19인치 기본 휠' },
        { label: '선택 품목', before: '스카이 라운지 루프', after: undefined },
        { label: '액세서리', before: undefined, after: '빌트인 블랙박스' },
      ]}
      summary="-2,800,000원"
    />
  );
}
```

`before`가 없으면 추가, `after`가 없으면 삭제, 둘 다 있으면 변경입니다. 가격 형식은 호출하는 쪽이 정하고 `summary`에 넘깁니다.

## 접근성

- 시맨틱 `table`입니다. `caption`(화면에는 숨김)이 표의 이름이고, 열 제목은 `scope="col"`, 항목 이름은 `scope="row"`라서 표 탐색 모드에서 스크린 리더가 셀마다 행과 열 이름을 함께 읽습니다(읽는 방식은 스크린 리더에 따라 다릅니다).
- 추가, 삭제, 변경은 색이 아니라 항목 이름 아래의 글자 표식으로 구분합니다.
- 비어 있는 칸은 화면에는 "—", 스크린 리더에는 "없음"으로 읽힙니다.
- 합계는 표의 마지막 줄(`tfoot`)이라 표 의미 안에 있습니다.
- 좁은 화면에서는 열이 줄어들고 긴 글자는 줄바꿈됩니다. 가로 스크롤이 생기지 않으며, 320px에서도 잘리지 않는 것을 확인했습니다.
