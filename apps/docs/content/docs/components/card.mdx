## 사용법

`Card`와 세 부품(`CardHeader`, `CardTitle`, `CardDescription`)을 조합합니다. 부품은 서로 독립이라 필요한 것만 쓰면 됩니다.

```tsx
import { Card, CardDescription, CardHeader, CardTitle } from '@/components/ui/card';

export function Example() {
  return (
    <Card>
      <CardHeader>
        <CardTitle>견적 안내</CardTitle>
        <CardDescription>취득세와 부대비용은 지역과 과세 구분에 따라 다릅니다.</CardDescription>
      </CardHeader>
    </Card>
  );
}
```

## API 레퍼런스

네 컴포넌트 모두 자기 요소의 모든 HTML 속성과 `className`을 받습니다. 따로 정의한 prop은 없습니다.

| 컴포넌트          | 렌더하는 요소 | 스타일                                    |
| ----------------- | ------------- | ----------------------------------------- |
| `Card`            | `div`         | `border-border bg-card rounded-lg border` |
| `CardHeader`      | `div`         | 세로 배치, 간격 6px, 안쪽 여백 24px       |
| `CardTitle`       | `h3`          | `text-foreground` 18px, 굵기 600          |
| `CardDescription` | `p`           | `text-muted-foreground`, 캡션 크기(14px)  |

## 접근성

- `CardTitle`은 항상 `h3`입니다. 페이지의 제목 수준과 맞지 않으면 `h2`나 `h4`가 필요한데, 지금은 요소를 바꾸는 prop이 없습니다. 제목 순서가 중요한 화면에서는 이 점을 확인하십시오.
- 카드 전체를 링크로 만들 때는 제목 안에 `<a>` 하나를 두고 그 링크를 카드 크기로 늘리는 방식을 쓰십시오. 카드 자체에 `onClick`을 달면 키보드로 접근할 수 없습니다.
- 그림자를 쓰지 않고 `border-border` 헤어라인으로 면을 나눕니다. 라이트와 다크 모두에서 보이는 두께와 색입니다 ([보더](/docs/foundations/border)).
