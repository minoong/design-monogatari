## 사용법

```tsx
import Link from 'next/link';

import { Stepper, StepperItem } from '@/components/ui/stepper';

export function Example({ current }: { current: string }) {
  return (
    <Stepper aria-label="견적 단계" value={current}>
      <StepperItem value="model" asChild completed>
        <Link href="/estimate/model">모델</Link>
      </StepperItem>
      <StepperItem value="color" asChild>
        <Link href="/estimate/color">외장 색상</Link>
      </StepperItem>
    </Stepper>
  );
}
```

`Stepper`의 `value`가 `StepperItem`의 `value`와 같으면 그 단계가 현재 단계가 됩니다. 번호는 목록 순서대로 자동으로 붙습니다. 모든 단계가 링크라서 순서와 관계없이 이동할 수 있고, 끝낸 단계는 `completed`로 표시합니다.

링크는 `href`를 주거나, `asChild`로 Next `Link` 같은 자식 요소에 스타일을 입히십시오. 같은 화면 안에서 단계를 바꾸는 용도라도 버튼이 아니라 링크(주소가 바뀌는 이동)로 쓰는 것을 전제로 합니다.

## 예시

### 좁은 폭

폭이 좁으면 목록이 가로로 스크롤되고, 현재 단계가 바뀔 때 그 단계가 가운데로 옮겨집니다. 아래에서 뒤쪽 단계를 눌러 보십시오. `prefers-reduced-motion`이 켜져 있으면 부드럽게 움직이지 않고 바로 이동합니다.

<ComponentPreview name="stepper/narrow" />

### 현재 단계 표시의 모양

`indicator`로 모양을 고릅니다. 어느 모양이든 단계가 바뀌면 표시가 이전 단계에서 새 단계로 넘치지 않고 미끄러지고, 감소 모션이면 바로 옮겨 갑니다. 기본은 `pill`입니다.

## 접근성

- `nav`와 `ol`이라서 스크린 리더가 "내비게이션, 목록 N개 항목"과 현재 위치를 알려 줍니다. `list-style: none`으로 목록 역할이 사라지는 Safari를 위해 `role="list"`를 명시했습니다. `nav`에는 `aria-label`로 이름을 꼭 달아야 합니다.
- 현재 단계에는 `aria-current="step"`이 붙습니다. 현재 표시는 어느 모양이든 표시 하나만으로는 약할 수 있어서(알약은 페이지와 거의 같은 밝기), 파란색으로 채워진 번호 배지와 굵은 글자가 함께 구분합니다. 알약은 호버 배경과 구분되도록 헤어라인(`border-border`) 테두리가 있습니다. 라이트에서는 호버 채움과 알약 채움이 같은 색이라 구분의 대부분을 파란 번호 배지와 굵은 글자가 맡습니다. 강제 색상 모드에서는 알약과 링은 `Highlight` 테두리, 막대는 `Highlight` 배경으로 남습니다. 알약은 단계가 바뀔 때 이전 단계에서 새 단계로 미끄러지고, 감소 모션이면 바로 옮겨 갑니다.
- 끝낸 단계는 체크 아이콘(장식)과 함께 "(완료)"가 스크린 리더에 읽힙니다.
- 단계를 끝낸 순간에만 체크가 그려집니다. 처음부터 끝난 단계는 움직이지 않고, 감소 모션이면 그려지지 않고 바로 나타납니다.
- 모든 단계가 링크이므로 Tab으로 하나씩 이동하고 Enter로 열립니다. 숫자 배지는 CSS 카운터로 그려서 스크린 리더에는 읽히지 않고, 목록이 순서를 알려 줍니다.
- 키보드 포커스는 2px 아웃라인(간격 2px)으로 보입니다. 각 항목의 높이는 44px입니다.
- 키보드로 포커스한 단계가 가장자리에 걸려 있으면 링이 잘리지 않게 안쪽으로 스크롤합니다. 현재 단계를 가운데로 옮기는 스크롤은 `prefers-reduced-motion`에서 즉시 이동으로 바뀝니다. 가로 스크롤바는 숨겨져 있으므로 마우스만 쓰는 사용자는 휠이나 터치 스와이프로 넘기고, 키보드 사용자는 Tab으로 이동하면 브라우저가 해당 항목을 보이는 곳으로 가져옵니다.
