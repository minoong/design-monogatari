## 사용법

```tsx
import { ColorSwatchGroup } from '@/components/ui/color-swatch-group';

export function Example() {
  const [value, setValue] = useState('white');

  return (
    <ColorSwatchGroup
      legend="외장 색상"
      name="color"
      value={value}
      onValueChange={setValue}
      options={[
        { value: 'white', label: '화이트', color: '#f2f2f0', price: '기본 포함' },
        { value: 'black', label: '블랙', color: '#1a1a1c', price: '기본 포함' },
      ]}
    />
  );
}
```

색 값(`color`)은 호출하는 쪽이 CSS 색으로 넘깁니다. 이 컴포넌트는 색을 정하지 않아서 디자인 토큰에도 새 색이 생기지 않습니다. 제어 컴포넌트라서 `value`와 `onValueChange`가 필요합니다.

`group`이 같은 칩은 소제목 아래 묶입니다(글로시, 메탈릭, 무광처럼). `group`을 주지 않으면 소제목 없이 한 줄로 이어집니다.

## 예시

### 선택할 수 없는 칩

`unavailableReason`이 있는 칩은 사선이 그어지고, 칩에 마우스를 올리거나 키보드로 포커스하거나 터치로 누르면 아래 캡션에 이름과 함께 이유가 보입니다(터치는 마지막으로 누른 칩이 남습니다). 선택 불가 칩이 하나라도 있으면 캡션 아래에 "사선이 그어진 색은 지금 고를 수 없습니다." 안내가 항상 보입니다(`unavailableHint`로 바꿉니다). 입력은 비활성이 아니라서 눌렀을 때 `onValueChange`가 호출됩니다. 방향키로 훑을 때도 호출되니, 모달은 명시적 동작에서 열고 `onValueChange`에서는 안내 문구 정도로 두십시오.

위 미리보기에서 "브론즈" 칩을 포커스해 보십시오.

## 접근성

- 칩마다 네이티브 라디오(시각적으로만 숨김)가 있어서 같은 `name`끼리 방향키로 옮겨 다닙니다. 그룹은 `fieldset`과 `legend`로 이름이 붙습니다.
- 칩의 접근성 이름은 `label`(`aria-label`)입니다. 색만으로 의미를 전하지 않습니다.
- 선택은 두 겹 링으로, 포커스는 4px 간격의 2px 아웃라인으로 보입니다. 선택 링은 요소 하나가 선택된 칩 위로 `SPRING.settle`로 미끄러지고(줄과 소제목을 가로질러 움직입니다), 감소 모션이면 바로 옮겨 갑니다. 강제 색상 모드에서는 box-shadow가 지워지므로 `Highlight` 아웃라인으로 남습니다. 선택 불가는 사선으로 표시해서 색 구분에 기대지 않습니다.
- 가격과 선택 불가 이유는 시각 캡션과 별개로 `aria-describedby`(화면에 안 보이는 설명)로 입력에 연결됩니다. 칩의 터치 영역은 36px입니다.
- 소제목이 있는 묶음은 `role="group"`과 소제목 이름으로 알립니다.
- 사선은 배경색 테두리가 둘러져 있어서 어떤 칩 색 위에서도 보입니다.
- 캡션은 `aria-live`가 아닙니다. 선택 상태는 라디오가 알립니다.
