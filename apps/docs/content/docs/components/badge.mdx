## 사용법

```tsx
import { Badge } from '@/components/ui/badge';

export function Example() {
  return <Badge variant="secondary">대기 중</Badge>;
}
```

배지는 정보를 알리는 용도예요. 눌러서 무언가를 하게 만드는 CTA 대신 쓰지 마세요.

## 예시

### 형태

`default`는 잉크 색 채움, `secondary`는 옅은 면에 헤어라인, `destructive`는 오류색 테두리예요.

## 접근성

- 의미를 **색으로만** 전달하지 마세요. `destructive`도 "한도 초과"처럼 글자가 상태를 말해야 해요.
- 글자와 배경의 대비는 토큰이 보장해요 (`default`는 잉크색 배경에 `background` 색 글자, `destructive`는 오류색 글자와 테두리). 값은 [색](/docs/foundations/colors) 페이지에서 볼 수 있어요.
- 상태가 바뀌는 것을 알려야 한다면 배지에 `role="status"`를 직접 달아 주세요. 기본은 일반 `<span>`이에요.
