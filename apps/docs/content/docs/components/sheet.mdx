## 사용법

```tsx
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from '@/components/ui/sheet';

export function Example() {
  return (
    <Sheet>
      <SheetTrigger asChild>
        <button>견적 요약 보기</button>
      </SheetTrigger>
      <SheetContent side="right">
        <SheetHeader>
          <SheetTitle>견적 요약</SheetTitle>
          <SheetDescription>선택하신 항목과 금액입니다.</SheetDescription>
        </SheetHeader>
        <SheetClose asChild>
          <button>닫기</button>
        </SheetClose>
      </SheetContent>
    </Sheet>
  );
}
```

`Sheet`는 [`Dialog`](/docs/components/dialog)와 같은 Radix 대화상자라서 `Sheet`, `SheetTrigger`, `SheetClose`, `SheetHeader`, `SheetTitle`, `SheetDescription`, `SheetFooter`는 `Dialog`의 같은 부품입니다. 다른 것은 `SheetContent`뿐이고, `side`로 어느 가장자리에서 나올지 정합니다.

<Callout type="warn" title="SheetTitle은 필수입니다">
  `SheetContent` 안에 `SheetTitle`이 없으면 접근 가능한 이름이 없습니다. 오버레이는 `SheetContent`가
  함께 그리니 따로 넣지 마십시오.
</Callout>

## 예시

### 아래에서 열기

모바일에서는 `side="bottom"`으로 요약을 보여 주고, 데스크톱에서는 `side="right"`로 엽니다. 아래에서 열리는 시트는 위쪽에 **핸들**(잡는 막대)이 있고, 핸들이나 제목, 푸터의 빈 곳을 아래로 끌어 닫습니다. 시트 높이의 30%를 넘게 끌거나 빠르게 쓸어내리면 닫히고, 아니면 제자리로 돌아옵니다. 목록과 버튼에서는 끌기가 시작되지 않습니다. 핸들을 끄려면 `handle={false}`를 줍니다.

<ComponentPreview name="sheet/bottom" />

### 긴 내용

내용이 시트보다 길면 `SheetBody`로 감쌉니다. 본문만 스크롤하고 제목과 푸터는 늘 보입니다. 끌어 닫는 시트(핸들이 켜진 아래 시트)는 시트 자체가 스크롤하지 않으므로 긴 내용에는 `SheetBody`가 필요하고, 본문을 스크롤하는 손가락은 시트를 끌지 않습니다.

<ComponentPreview name="sheet/bottom-scroll" />

터치에서는 본문이 맨 위에 있을 때 손가락으로 아래로 끌면 본문이 스크롤되는 대신 시트가 따라 내려가 닫을 수 있습니다. 본문이 조금이라도 스크롤된 상태에서는 스크롤이 그대로 일어나므로, 시트를 끌려면 핸들, 제목, 푸터의 빈 곳을 끕니다.

### 겹쳐 열기

시트 안에서 다른 시트를 열면 바깥 시트가 한 칸 뒤로 물러나고(5% 작아집니다) 안쪽 시트가 그 위에 열립니다. 바깥 시트의 크기는 안쪽 시트가 열린 정도에서 계산되어, 안쪽 시트의 핸들을 아래로 끌면 끄는 만큼 바깥 시트가 원래 크기로 돌아오고(절반쯤 내리면 2.5% 작은 상태) 다시 올리면 작아집니다. 안쪽을 닫으면 바깥 시트가 원래대로 돌아옵니다. 아래 시트에만 적용되고, 감소 모션이면 크기가 바뀌지 않습니다.

<ComponentPreview name="sheet/nested" />

### 높이를 고르기

`snapPoints`에 화면 높이에 대한 비율을 오름차순으로 주면 아래 시트가 그 높이들에 멈춥니다(예: `[0.4, 0.85]`). 가장 큰 값이 시트의 높이이고 처음에는 `defaultSnapIndex`번 높이만큼 보입니다. 핸들이나 본문을 끌어 놓으면 놓은 뒤의 속도까지 계산해 가장 가까운 높이로 맞춰지고, 가장 낮은 높이보다 더 내려놓으면 닫힙니다. 가장 큰 높이가 아닐 때는 본문이 스크롤하지 않고 본문을 위아래로 끌어 높이를 바꾸며, 가장 큰 높이에서만 본문이 스크롤합니다.

## 접근성

- Radix Dialog가 포커스를 맡습니다. 열리면 포커스가 패널 안으로 들어가고 열려 있는 동안 Tab이 패널 안에서만 돌며, Esc로 닫히고 닫히면 포커스가 연 버튼으로 돌아옵니다.
- `SheetTitle`이 이름(`aria-labelledby`), `SheetDescription`이 설명(`aria-describedby`)입니다.
- 열리고 닫힐 때 0.28초 동안 가장자리에서 화면 끝까지 미끄러지듯 들어오고 나갑니다(투명도는 바꾸지 않아 닫힐 때 중간에서 사라지지 않습니다). 뒤의 배경은 시트가 내려간 정도에 따라 짙기가 계산되어, 끌면 손가락을 따라 옅어지고 열고 닫을 때는 시트와 같은 속도로 바뀝니다. `prefers-reduced-motion`이면 움직이지 않고 바로 나타납니다.
- 아래 시트의 끌어 닫기는 보조 수단입니다. 핸들은 `aria-hidden`이고 포커스를 받지 않으며, 키보드와 낭독기 사용자는 Esc나 닫기 버튼으로 닫습니다. 끌기는 핸들, 제목, 푸터의 빈 곳에서 시작하고 버튼, 링크, 입력에서는 시작하지 않습니다. `SheetBody`(스크롤하는 본문)에서는 마우스로는 글자를 선택하고, 터치로는 본문이 맨 위일 때 아래로 끌면 시트가 따라 내려갑니다(맨 위가 아니면 스크롤). 아래로만 끌립니다(위로는 막힘). 안쪽 시트가 열려 있으면 바깥 시트는 뒤로 물러나 있습니다.
- 오버레이를 누르면 닫힙니다. 시트에는 닫기 버튼이 따로 없으니 `SheetClose`로 닫기 버튼을 넣으십시오(터치 사용자는 오버레이를 누르거나 이 버튼으로 닫습니다). 왼쪽·오른쪽 시트의 폭은 화면보다 2rem 좁아서 모바일에서도 뒤 화면이 조금 보이고, 위·아래 시트는 화면 폭 전체입니다.
