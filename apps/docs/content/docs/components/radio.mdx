## 사용법

```tsx
import { Label } from '@/components/ui/label';
import { Radio } from '@/components/ui/radio';

export function Example() {
  return (
    <fieldset>
      <legend>과세 구분</legend>
      <Radio id="taxable" name="tax" value="taxable" defaultChecked />
      <Label htmlFor="taxable">과세</Label>
      <Radio id="exempt" name="tax" value="exempt" />
      <Label htmlFor="exempt">면세</Label>
    </fieldset>
  );
}
```

`Radio`는 입력 칸만 그립니다. 보이는 이름표는 [`Label`](/docs/components/label)을 `htmlFor`로 이어 주십시오. 설명이나 가격이 붙는 한 줄짜리 선택지는 [`OptionRow`](/docs/components/option-row)가 더 알맞습니다.

## 예시

### 상태

기본, 선택됨, 오류, 비활성입니다. 상태는 prop이 아니라 HTML 속성(`checked`, `aria-invalid`, `disabled`)으로 정합니다. 비활성은 투명도를 낮추지 않고 `muted` 면을 써서 대비가 유지됩니다.

## API 레퍼런스

`<input>`의 모든 속성과 `ref`를 받습니다(`type`은 `radio`로 고정입니다). 정의된 prop은 없습니다.

선택 표시는 테두리 색과 안쪽 점입니다. 색 하나에만 기대지 않아서 점 유무로도 구분됩니다. 지름은 20px입니다.

## 접근성

- 네이티브 `<input type="radio">`라서 역할과 선택 상태를 브라우저가 알려 줍니다.
- 같은 `name`끼리는 Tab으로 그룹에 한 번 들어가고 방향키로 항목을 옮깁니다. 이 동작은 브라우저가 맡습니다.
- 그룹 이름은 `fieldset`과 `legend`로 달아 주십시오.
- 선택되면 0.32초 튀어 오르고, 같은 묶음에서 다른 항목이 선택돼 해제되면 선택 표시가 0.2초 동안 줄어들며 사라집니다. 처음 그려질 때는 움직이지 않으며 감소 모션이면 꺼집니다.
- 키보드 포커스는 두 겹 링(`ring-2 ring-ring`, 간격 2px)으로 보입니다.
- 오류는 `aria-invalid`로 알리고, 안내 문구는 `aria-describedby`로 연결하십시오.
- 고대비(forced-colors) 모드에서는 브라우저 기본 라디오로 돌아갑니다. 포커스 링은 투명 아웃라인(`outline-hidden`)을 함께 써서 고대비에서도 보입니다.
- 입력 칸만으로는 지름이 20px이라 터치 영역이 24px에 못 미칩니다. 문서 예시처럼 `Label`(`htmlFor`)과 함께 써서 글자까지 눌리게 하십시오.
