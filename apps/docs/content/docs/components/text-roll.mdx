## 사용법

```tsx
import { TextRoll } from '@/components/ui/text-roll';

<h2>
  <TextRoll>{stepLabel}</TextRoll>
</h2>;
```

단계 제목처럼 한 자리에서 짧은 글자만 바뀌는 곳에 씁니다. 글자(`children`)가 바뀌면 이전 글자는 위로 한 줄만큼 밀려 나가고, 새 글자는 그 바로 아래에서 같은 거리를 같은 곡선으로 올라옵니다. 둘이 거의 틈 없이 이어져 한 줄이 위로 굴러가는 것처럼 보입니다. 글자 전체가 한 덩어리로 한꺼번에 움직여서 순서가 섞이거나 겹치지 않습니다. 이전 단계로 돌아갈 때는 `direction="down"`으로 반대 방향으로 굴립니다.

- 처음 그려질 때는 움직이지 않습니다. 화면이 열릴 때마다 움직이면 방해가 됩니다.
- 짧은 제목에 맞습니다. 두 글자의 줄 수가 다르면 움직이는 거리가 달라 이어 붙는 느낌이 줄어들고, 연달아 빠르게 바꾸면 이전 글자가 잠깐 겹쳐 보입니다.
- 움직이지 않고 바로 바뀌는 것이 필요하면 `TextRoll`을 쓰지 말고 글자를 그대로 두십시오.
- 크기와 굵기는 감싸는 요소(`h2`, `p`)의 글자 스타일을 그대로 따릅니다.

## 접근성

- 낭독기는 화면에 보이지 않는 한 벌의 글자(`sr-only`)만 읽습니다. 움직이는 글자는 `aria-hidden`이라 중간 상태나 이전 글자를 읽지 않습니다.
- 글자가 바뀌어도 알림(`aria-live`)을 따로 내지 않습니다. 단계 제목이라면 제목으로 포커스를 옮기는 쪽이 낭독기에 더 잘 닿습니다.
- 감소 모션 설정이면 이동 없이 짧은 페이드로 바로 바뀝니다.
- 키보드로 닿는 요소가 아니고, 색과 대비는 감싸는 글자를 따릅니다.
