## 사용법

```tsx
import { Button } from '@/components/ui/button';

export function Example() {
  return <Button variant="primary">시작하기</Button>;
}
```

`variant`를 생략하면 `secondary`(테두리만 있는 버튼)가 됩니다. 화면의 핵심 행동 하나에만 `primary`를 쓰십시오.

## 예시

### 변형

`primary`는 채워진 버튼, `secondary`는 테두리만 있는 버튼, `clear`는 호버 전까지 배경이 없는 버튼입니다.

<ComponentPreview name="button/variants" />

### 크기

`small`(32px), `medium`(40px), `large`(48px, 기본값), `xlarge`(56px)가 있습니다.

<ComponentPreview name="button/sizes" />

### 모서리

`md`, `lg`(기본값), `pill`입니다.

<ComponentPreview name="button/radius" />

### 너비

`inline`(기본값)은 내용만큼, `block`은 부모 너비만큼, `full`은 부모 너비를 채우고 남는 공간까지 차지합니다.

<ComponentPreview name="button/display" />

### 아이콘과 함께

아이콘에 `data-icon="inline-start"` 또는 `data-icon="inline-end"`를 달면 그쪽 안쪽 여백이 줄어서 글자와 균형이 맞습니다. 이 예시의 아이콘은 호버하면 움직이는 애니메이션 아이콘입니다. 다른 SVG 아이콘도 같은 방식으로 쓸 수 있습니다.

<ComponentPreview name="button/with-icon" />

### 아이콘만

`icon`을 켜면 정사각형 버튼이 됩니다. 글자가 없으니 `aria-label`을 꼭 달아야 합니다.

<ComponentPreview name="button/icon-only" />

### 로딩

`loading`을 켜면 글자 대신 점 세 개가 움직이고, 클릭은 무시됩니다. 버튼 크기는 그대로 유지됩니다.

<ComponentPreview name="button/loading" />

### 링크로 렌더링

`asChild`를 켜면 `<button>` 대신 자식 요소를 버튼 모양으로 렌더합니다. 이동이 목적이면 `<button>`이 아니라 링크가 맞아서, 이럴 때 씁니다.

<ComponentPreview name="button/as-child" />

## 접근성

- 기본 요소가 `<button type="button">`이라서 키보드(Tab, Enter, Space)로 조작하고, 폼 안에서 의도치 않게 제출되지 않습니다.
- 키보드 포커스에서만 링 두 겹이 나타납니다(`focus-visible`). `primary`는 링과 버튼 사이에 배경색 간격이 생깁니다.
- `loading` 동안 `aria-busy`가 설정되고 클릭 핸들러가 호출되지 않습니다.
- `disabled`는 투명도 40%로 흐려지고 포인터 이벤트를 받지 않습니다.
- 누를 때 줄어드는 움직임은 `prefers-reduced-motion`을 켜면 사라집니다.
- `icon` 버튼과 `asChild`로 만든 아이콘 링크에는 `aria-label`을 직접 달아야 합니다.
