## 사용법

```tsx
import { AnimatedAmount } from '@/components/ui/animated-amount';

export function Example({ total }: { total: number }) {
  return <AnimatedAmount value={total} className="text-title font-semibold" />;
}
```

`value`가 바뀔 때마다 자릿수별로 굴러갑니다. 처음 나타날 때는 애니메이션 없이 바로 보여 줍니다(`animate`로 끌 수도 있습니다). 소수 자릿수는 `format`을 따릅니다. 기본은 정수라서 반올림합니다.

## 예시

### 접두사, 접미사, 형식

기본은 `ko-KR`로 정수에 앞에 `₩`을 붙입니다(`prefix`와 `suffix`를 둘 다 안 줄 때만이고, 하나라도 주면 `₩`은 붙지 않습니다). `prefix`, `suffix`로 앞뒤 글자를, `format`으로 `Intl.NumberFormat` 옵션을 바꿀 수 있습니다.

<ComponentPreview name="animated-amount/affixes" />

### 화면에 들어올 때 시작

`inView`를 켜면 요소가 화면에 보일 때까지 숨겨 두었다가 0에서 값까지 굴러갑니다. 한 번만 실행되고(`inViewOnce`), 스크롤 위치 기준은 `inViewAmount`, `inViewMargin`, `inViewRoot`로 조절합니다.

```tsx
<AnimatedAmount value={52_900_000} inView />
```

## 접근성

숫자는 [NumberFlow](https://number-flow.barvian.me/)로 그립니다. 스크린 리더에는 이렇게 노출됩니다 (Chrome 접근성 트리로 확인).

- 숫자는 `image` 역할에 `aria-label="1,250,000"`처럼 **쉼표가 들어간 최종 값**이 이름입니다. 값이 바뀌면 이름도 바뀝니다.
- 단위(`₩`)와 `prefix`, `suffix`는 숫자 밖의 일반 텍스트라서, 스크린 리더가 "₩", "이미지 1,250,000"을 **따로** 읽을 수 있습니다.
- 폭을 잡아 두는 보이지 않는 글자는 `aria-hidden`이라 중복해서 읽히지 않습니다.
- `prefers-reduced-motion`을 켜면 굴러가는 애니메이션 없이 값이 바로 바뀝니다.

금액이 화면의 핵심이라면 값이 바뀔 때 알려야 하는지 직접 판단하십시오. 바뀐 금액을 알려야 하면 바깥에 `aria-live="polite"` 영역을 두고 "1,250,000원"처럼 단위까지 한 문장으로 넣는 방법을 권합니다.
