## 사용법

```tsx
import { NativeSelect } from '@/components/ui/native-select';

export function Example() {
  return (
    <NativeSelect aria-label="탁송지" defaultValue="seoul">
      <option value="seoul">서울</option>
      <option value="busan">부산</option>
    </NativeSelect>
  );
}
```

지역이나 과세 구분처럼 짧고 닫힌 목록에 알맞아요. 옵션을 직접 그리거나 검색해야 하는 목록이라면 쓰지 마세요. 옵션 목록은 꾸미지 않고 브라우저에 맡겨요.

[`Field`](/docs/components/field)와 함께 쓰면 이름표와 오류 문구까지 한 번에 묶여요.

## API 레퍼런스

`<select>`의 모든 속성과 `ref`를 받아요. 정의된 prop은 없어요. `className`은 `<select>`에 붙어요.

높이는 44px(`h-11`), 모서리는 `rounded-md`예요. 오른쪽 화살표는 장식이라 클릭을 가로채지 않아요(`pointer-events-none`).

## 접근성

- 네이티브 `<select>`라서 역할, 열기/닫기, 방향키와 글자 입력으로 항목 찾기를 브라우저와 스크린 리더가 그대로 처리해요.
- 보이는 이름표는 `Label`/`FieldLabel`을 `htmlFor`로 잇고, 이름표가 없는 자리에는 `aria-label`을 다세요.
- 오류는 `aria-invalid`로 알리고 안내 문구를 `aria-describedby`로 연결하세요.
- 화살표 아이콘은 `aria-hidden`이에요.
