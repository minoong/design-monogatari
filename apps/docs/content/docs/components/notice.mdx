## 사용법

```tsx
import { Notice, NoticeDescription, NoticeTitle } from '@/components/ui/notice';

export function Example() {
  return (
    <Notice variant="error">
      <NoticeTitle>탁송지를 선택해 주십시오</NoticeTitle>
      <NoticeDescription>견적을 완료하려면 탁송 지역이 필요합니다.</NoticeDescription>
    </Notice>
  );
}
```

잠깐 보였다 사라지는 알림은 [`Toast`](/docs/components/toast)를 쓰십시오. 사용자의 응답이 필요하면 [`Dialog`](/docs/components/dialog)를 쓰십시오.

## 예시

위 미리보기가 정보(`info`, 기본)와 오류(`error`)입니다.

## API 레퍼런스

`<div>`의 모든 속성을 받습니다. `NoticeTitle`과 `NoticeDescription`은 `<p>`의 모든 속성을 받습니다.

<PropsTable

  }}
/>

## 접근성

- 오류는 `role="alert"`라서 화면에 나타나는 순간 즉시 읽힙니다. 정보는 `role="status"`이지만, 이미 글자가 들어 있는 채로 DOM에 새로 들어온 `status`는 스크린 리더가 읽지 않는 경우가 많습니다. 정보를 확실히 읽히게 하려면 `Notice`를 계속 그려 두고 안의 글자를 바꾸십시오.
- 오류는 색만으로 구분하지 않습니다. 테두리가 2px로 굵고 제목은 `destructive` 색이며 본문은 `foreground`를 씁니다. 스크린 리더에는 제목 앞에 "오류: "가 읽힙니다(`NoticeTitle`의 `errorLabel`로 바꿉니다).
- 정보 문구는 `muted` 면 위의 `muted-foreground`(대비 4.66:1 이상)입니다.
