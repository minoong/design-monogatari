## 사용법

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from '@/components/ui/dialog';

export function Example() {
  return (
    <Dialog>
      <DialogTrigger asChild>
        <button type="button">열기</button>
      </DialogTrigger>
      <DialogContent>
        <DialogHeader>
          <DialogTitle>제목</DialogTitle>
          <DialogDescription>설명</DialogDescription>
        </DialogHeader>
        <DialogFooter>
          <DialogClose asChild>
            <button type="button">닫기</button>
          </DialogClose>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  );
}
```

부품은 서로 열림 상태를 나눠 가집니다. 하나의 큰 컴포넌트로 합치지 않았습니다.

<Callout type="warn" title="DialogTitle은 필수입니다">
  `DialogContent` 안에 `DialogTitle`이 있어야 창에 접근 가능한 이름이 생깁니다. 또 `DialogContent`가
  **어두운 막(overlay)을 이미 그립니다**. `DialogOverlay`를 형제로 또 넣으면 막이 두 겹이 됩니다.
</Callout>

## API 레퍼런스

### Dialog

[Radix Dialog.Root](https://www.radix-ui.com/primitives/docs/components/dialog#root)의 props를 받습니다. 열림 상태를 직접 관리하지 않으면(`open`이 없으면) 내부 상태를 씁니다.

| 속성           | 타입                      | 기본값  | 설명                                               |
| -------------- | ------------------------- | ------- | -------------------------------------------------- |
| `open`         | `boolean`                 | -       | 열림 상태. 주면 제어 컴포넌트가 됩니다.            |
| `defaultOpen`  | `boolean`                 | `false` | 처음에 열려 있을지. 제어하지 않을 때만 씁니다.     |
| `onOpenChange` | `(open: boolean) => void` | -       | Esc, 바깥 클릭, 닫기 버튼 등 모든 변화를 알립니다. |
| `modal`        | `boolean`                 | `true`  | 열려 있는 동안 바깥 상호작용을 막을지 (Radix).     |

### 부품

| 컴포넌트            | 설명                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `DialogTrigger`     | 창을 여는 요소. `asChild`로 내 버튼을 쓰십시오.                                                                                  |
| `DialogContent`     | 창 본체. 어두운 막과 함께 포털에 그려지고, 열고 닫을 때 투명도와 크기(0.96배)가 0.15초 움직입니다.                               |
| `DialogHeader`      | 제목과 설명을 묶는 영역. 작은 화면에서는 가운데, 넓은 화면에서는 왼쪽 정렬입니다.                                                |
| `DialogTitle`       | **필수.** 창의 이름입니다.                                                                                                       |
| `DialogDescription` | 창 설명. 없으면 Radix가 콘솔 경고를 냅니다. 설명이 정말 필요 없으면 `DialogContent`에 `aria-describedby={undefined}`를 주십시오. |
| `DialogFooter`      | 버튼 영역. 작은 화면에서는 세로로, 넓은 화면에서는 오른쪽 정렬로 가로 배치됩니다.                                                |
| `DialogClose`       | 창을 닫는 요소. `asChild`로 내 버튼을 쓰십시오.                                                                                  |
| `DialogOverlay`     | 어두운 막. `DialogContent`가 이미 그리니 직접 쓰지 마십시오. 커스텀 포털을 만들 때만 씁니다.                                     |

## 접근성

Radix Dialog가 아래를 맡습니다.

- 열리면 포커스가 창 안으로 들어가고, 열려 있는 동안 Tab이 창 안에서만 돕니다.
- Esc로 닫힙니다. 닫히면 포커스가 창을 연 요소로 돌아갑니다.
- `DialogTitle`이 창의 이름(`aria-labelledby`), `DialogDescription`이 설명(`aria-describedby`)이 됩니다.
- 움직임은 `prefers-reduced-motion`을 켜면 사라집니다 (투명도·크기 전환 없이 바로 나타납니다).
