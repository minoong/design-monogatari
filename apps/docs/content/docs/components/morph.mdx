## 사용법

```tsx
import { useState } from 'react';

import { Morph } from '@/components/ui/morph';

export function Corner({ inside }: { inside: boolean }) {
  const [open, setOpen] = useState(false);
  return (
    <Morph
      className="border-border bg-background/95 border backdrop-blur-sm"
      order={['switch', 'note']}
      radii={{ switch: 18, note: 8 }}
      value={inside ? 'note' : 'switch'}
    >
      {inside ? (
        <p className="px-2.5 py-1.5">안내 문구</p>
      ) : (
        <div className="flex py-1 pr-3 pl-1">
          <SunroofSwitch checked={open} onChange={(event) => setOpen(event.target.checked)} />
        </div>
      )}
    </Morph>
  );
}
```

같은 자리에 놓이는 두 가지 내용이 조건에 따라 바뀔 때(차량 위 모서리의 선루프 스위치와 안쪽 시점 안내처럼), 한쪽이 사라지고 다른 쪽이 나타나는 대신 하나의 틀이 변합니다. `value`가 바뀌면 틀이 새 내용의 크기로 스프링(`SPRING.settle`)을 따라 늘고 줄며 모서리 반경도 함께 바뀌고, 안의 내용은 틀 안에서 옆으로 밀려 나가고 들어옵니다. 투명도는 바꾸지 않습니다. 반투명한 중간 상태 없이, 항상 또렷한 채로 바뀝니다. 내용은 틀 안에서 잘려서 밖으로 새지 않습니다.

`children`에는 지금 `value`에 해당하는 내용 하나만 넘깁니다. `children`과 `value`는 같은 렌더에서 함께 바꾸십시오. 어긋나면 같은 내용이 둘 겹쳐 지나가거나 한 프레임 낡은 내용이 보입니다. 내용이 바뀌는 순간 나가는 내용은 `Morph`가 그대로 붙잡고 밀어내므로, 이전 내용을 따로 보관하지 않아도 됩니다.

안의 컨트롤 상태는 부모가 들고(제어 컴포넌트) 있어야 합니다. `value`가 바뀌면 안의 요소가 새로 만들어지므로, 비제어로 두면 왕복할 때 처음 값으로 돌아갑니다. 안의 컨트롤에는 고정 `id`나 `htmlFor`를 주지 마십시오. 나가는 내용이 남아 있는 동안 같은 `id`가 둘이 됩니다.

크기를 움직이는 예외입니다. 모션 문서의 "`opacity`와 `transform`만 움직인다"는 규칙은 보통 레이아웃이 밀리는 것을 막으려는 것인데, `Morph`는 Motion의 `layout`이 틀의 크기를 변환으로 바꿔 옮기므로 주변 배치를 밀지 않습니다. 대신 틀의 크기가 바뀌면 주변이 그만큼 비켜 주지 않으므로, 절대 위치로 얹은 알약처럼 자리를 내줄 필요가 없는 작은 틀에 쓰십시오. 조건에 따라 담기고 빠지는 컨트롤은 [`Presence`](/docs/components/presence)를 쓰십시오.

## 예시

### 처음에도 움직이기

처음부터 `value`가 있으면 처음 그릴 때 틀이 움직이지 않습니다(화면을 열 때 갑자기 움직이지 않게). 처음에도 밀려들게 하려면 `animateOnMount`를 켜십시오.

### 사라지기

`value`가 `null`이면 틀이 왼쪽으로 밀려나며 사라집니다. 틀은 자기 자리 밖으로 나가므로, 가려야 하면 부모에 `overflow: hidden`을 주십시오.

## 접근성

- 틀은 의미 없는 `div`입니다. 접근성 이름과 역할은 안의 내용이 가집니다(스위치는 `role="switch"`, 안내 문구는 글자).
- 나가는 내용과 사라지는 틀은 `inert`라서 포커스와 클릭을 받지 않고, 접근성 트리에서도 바로 빠집니다. 움직임이 끝나면 DOM에서 내려갑니다.
- 내용이 바뀌거나 틀이 나타날 때 낭독기에 따로 알리지 않습니다. 안내 문구처럼 알려야 하는 정보는 `Morph` 밖의 `role="status"` 영역에 따로 말해 주십시오(견적 앱은 시점을 알리는 영역에 안내 문구를 함께 넣습니다).
- 틀 위에 옅은 글자색(`text-muted-foreground`)을 올릴 때는 틀 배경을 95% 이상 불투명하게 두십시오. 85%에서는 어두운 배경 위에서 4.5:1 아래로 떨어질 수 있습니다.
- 안의 포커스가 있는 채로 내용이 바뀌면 포커스가 `body`로 떨어질 수 있습니다(브라우저마다 다릅니다). 내용을 바꾸는 컨트롤이 `Morph` 밖에 있으면(시점 버튼처럼) 포커스가 그 컨트롤에 있으므로 안전합니다. 안에서 바꾸는 경우에는 바꾸기 전에 호출하는 쪽이 포커스를 바꾼 컨트롤로 옮기십시오.
- 틀은 안을 잘라 내므로(`overflow: clip`), 틀 안 내용의 포커스 링이 가장자리에서 잘리지 않도록 내용 쪽에 링 두께(스위치는 4px) 이상의 여유를 두십시오. 위 예시처럼 스위치에는 위아래와 왼쪽에 안쪽 여백을 줍니다.
- `prefers-reduced-motion`이면 움직임 없이 바로 바뀝니다.
