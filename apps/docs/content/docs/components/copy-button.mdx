## 사용법

```tsx
import { CopyButton } from '@/components/ui/copy-button';

export function Example({ url }: { url: string }) {
  return <CopyButton value={url} label="링크 복사" />;
}
```

[`Button`](/docs/components/button) 위에 만들었으므로 `variant`, `size`, `radius` 등을 그대로 받고 기본값도 `Button`과 같습니다. 옆에 `Button`을 놓아도 높이와 모양이 어긋나지 않습니다. 누르면 문구가 "복사했습니다"로 바뀌었다가 2초 뒤 돌아옵니다.

## 예시

### 아이콘만

`iconOnly`를 주면 글자 없이 정사각형 아이콘 버튼이 됩니다. 문구는 화면에서만 숨기고 접근성 이름으로 남아서, 복사하면 "복사했습니다"로 바뀌어 읽힙니다.

<ComponentPreview name="copy-button/icon-only" />

### 복사한 뒤 알림 띄우기

`onCopy`는 복사가 성공한 뒤에 호출됩니다. [`Toast`](/docs/components/toast)와 함께 쓰면 버튼 문구 말고도 화면 한쪽에 결과가 남습니다.

## 접근성

- 네이티브 `<button>`이라 Enter와 Space로 누릅니다. 아이콘은 장식이라 숨기고, 이름은 버튼 안의 문구입니다.
- 결과는 항상 그려 둔 알림 줄이 읽어 줍니다. 성공은 조용한 `role="status"`, 실패는 즉시 읽는 `role="alert"`입니다. 같은 결과가 연달아 나와도 알림 문구를 새로 그려 다시 읽힙니다. 버튼의 이름도 함께 바뀌므로 스크린 리더에 따라 이름과 알림이 모두 들릴 수 있습니다.
- `aria-label`은 받지 않습니다. 이름이 고정되면 상태 문구가 가려지기 때문입니다.
- 알림 줄이 버튼 옆 형제로 그려집니다. `space-x-*`, `divide-x`, `:last-child` 기준으로 꾸미는 묶음 안에서는 쓰지 마십시오.
- 모든 문구를 겹쳐 두고 현재 것만 보여서, 문구가 바뀌어도 버튼 너비가 변하지 않습니다. 숨긴 문구는 `visibility: hidden`이라 스크린 리더가 읽지 않습니다.
- 클립보드는 보안 연결(HTTPS 또는 localhost)에서만 쓸 수 있습니다. 쓸 수 없으면 실패 문구로 바뀝니다.
- 눌림 반응은 `Button`의 Motion `whileTap`을 따르고 감소 모션을 지킵니다.
