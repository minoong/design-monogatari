## 사용법

```tsx
import { List, ListItem } from '@/components/ui/list';

export function InteriorColor() {
  return (
    <List selectable aria-label="내장 색상" defaultValue="black" onValueChange={console.log}>
      <ListItem value="black">블랙 비건 가죽</ListItem>
      <ListItem value="cognac">코냑 비건 가죽</ListItem>
    </List>
  );
}
```

`selectable` 없이 쓰면 선택 없이 항목을 보여주기만 하는 `list`입니다. 선택 가능한 목록에서는 `ListItem`에 `value`가 꼭 필요합니다(없으면 오류를 던집니다). `value`와 `onValueChange`로 제어하거나, `defaultValue`로 비제어로 쓸 수 있습니다.

항목마다 설명이나 가격이 붙고 한 줄이 곧 폼 입력이어야 하면 [`OptionRow`](/docs/components/option-row)를, 둘에서 넷의 짧은 선택지는 [`Segmented`](/docs/components/segmented)를 쓰십시오. 이 목록은 폼으로 전송되지 않습니다(`name`이 없습니다).

항목은 첫 그림에서 40ms 간격으로 차례로 나타나고, 나중에 추가된 항목은 지연 없이 나타납니다. 자바스크립트가 실행되기 전까지 항목이 숨겨져 있으므로, 첫 화면 위쪽에 있는 내용에는 쓰지 마십시오.

## 접근성

- `selectable` 목록은 `role="listbox"`, 항목은 `role="option"`이고 `aria-selected`로 선택을 알립니다. 비활성 항목은 `aria-disabled`입니다. 목록에는 `aria-label`이나 `aria-labelledby`로 이름을 주십시오. 선택하지 않는 목록은 `role="list"`입니다(목록 스타일을 지운 `ul`은 사파리와 VoiceOver가 목록으로 읽지 않기 때문에 역할을 명시합니다). 이름은 주지 않아도 됩니다.
- Tab은 목록에 한 번만 들어갑니다: 마지막으로 포커스가 있던 항목, 없으면 선택된 항목, 없으면 첫 항목으로 들어가고 나머지는 `tabindex="-1"`입니다. 위·아래 방향키, Home, End로 옮기고(처음과 끝에서 돌지 않습니다), 글자 키를 치면 그 글자로 시작하는 항목으로 갑니다(같은 글자를 거듭 치면 차례로 돕니다, 입력이 0.5초 멈추면 처음부터 다시 맞춥니다. Space는 언제나 선택이라 띄어쓰기가 든 글자 묶음은 맞추지 못합니다). Enter와 Space로 고르며, 방향키만으로는 선택이 바뀌지 않습니다. 비활성 항목은 포커스를 받지 않고 건너뜁니다.
- 한글 입력기로 조합하는 중의 글자 입력은 확인하지 않았습니다(조합 중에는 글자 키 이벤트가 오지 않을 수 있습니다).
- 선택은 색뿐 아니라 오른쪽 체크 표시와 왼쪽 안쪽 막대로도 알립니다(호버는 같은 배경색이라 막대와 체크가 선택과 호버를 가릅니다). 체크 자리는 항상 잡혀 있어 선택이 바뀌어도 줄이 밀리지 않습니다. 윈도 고대비 같은 강제 색상 모드에서는 막대가 사라지고 체크가 글자색을 따라 남습니다. 비활성 항목의 글자는 강제 색상 모드에서 `GrayText`입니다.
- `aria-disabled`는 이유를 알려 주지 않습니다. 고를 수 없는 이유는 항목 글자에 적으십시오(예: "타르투포 (재고 없음)").
- 옵션 안에 버튼이나 링크를 넣지 마십시오: 옵션이 이미 상호작용 요소라 중첩됩니다.
- 키보드 포커스는 항목 안쪽의 2px 아웃라인입니다(목록이 `overflow-hidden`이라 바깥으로 그리면 잘립니다).
- 항목 높이는 44px 이상입니다.
- 감소 모션이면 이동 없이 짧게 나타납니다. 중요한 내용을 모션만으로 알리지 않습니다.
- 실제 스크린 리더로 낭독을 확인하지 않았습니다. 접근성 트리의 역할과 상태만 확인했습니다.
