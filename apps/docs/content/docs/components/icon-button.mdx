## 설치

<InstallTabs name="icon-button" />

`IconButton`은 `Button`을 감싸서 만듭니다. 설치하면 `Button`도 함께 들어옵니다.

## 사용법

```tsx
import { IconButton } from '@/components/ui/icon-button';
import { Heart } from 'lucide-react';

export function Example() {
  return (
    <IconButton aria-label="관심 차량 담기">
      <Heart />
    </IconButton>
  );
}
```

아이콘은 어떤 SVG든 괜찮습니다. 위 예시는 shadcn 프로젝트에 흔한 `lucide-react`를 썼고, 이 문서의 미리보기는 호버하면 움직이는 애니메이션 아이콘입니다.

아이콘과 글자를 함께 쓸 때는 `IconButton`이 아니라 [`Button`](/docs/components/button)을 쓰십시오.

## 예시

### 형태

기본은 `clear`입니다. 호버하기 전까지 배경이 없어서 도구 모음처럼 아이콘이 여럿일 때 조용합니다. 강조할 하나에만 `primary`를 쓰십시오.

<ComponentPreview name="icon-button/variants" />

### 크기

`Button`과 같은 크기 단계입니다. 정사각형이라 `small` 32px, `medium` 40px, `large` 48px, `xlarge` 56px가 한 변입니다.

<ComponentPreview name="icon-button/sizes" />

### 모서리

기본은 `md`입니다. `Button`의 기본 `lg`와 다르니 같이 놓을 때 맞춰 주십시오.

<ComponentPreview name="icon-button/radius" />

## API 레퍼런스

`Button`의 props에서 `icon`과 `display`를 뺀 것이고, `aria-label`이 필수입니다. 기본값이 `Button`과 다른 `variant`와 `radius`를 표에 적었습니다. 나머지 `<button>` 속성은 그대로 받습니다.

## 접근성

- 보이는 글자가 없으니 스크린 리더는 `aria-label`로만 버튼을 압니다. 타입이 필수로 강제합니다. 아이콘의 모양이 아니라 **동작**을 적으십시오 ("하트" 대신 "관심 차량 담기").
- 키보드 포커스에서만 링이 나타납니다. 누를 때 0.9배로 줄어드는 움직임은 `prefers-reduced-motion`을 켜면 사라집니다.
- 터치 대상은 `small`이 32px입니다. 모바일에서 촘촘히 놓을 때는 `medium` 이상을 쓰십시오.
