## 사용법

```tsx
import { Checkbox } from '@/components/ui/checkbox';
import { Label } from '@/components/ui/label';

export function Example() {
  return (
    <div>
      <Checkbox id="mat" defaultChecked />
      <Label htmlFor="mat">프리미엄 플로어 매트</Label>
    </div>
  );
}
```

`Checkbox`는 입력 칸만 그립니다. 보이는 이름표는 [`Label`](/docs/components/label)을 `htmlFor`로 이어 주십시오. 하나만 고르는 자리는 [`Radio`](/docs/components/radio), 설명과 가격이 붙는 선택 품목 한 줄은 [`PackageRow`](/docs/components/package-row)가 알맞습니다.

## 예시

### 상태

기본, 선택됨, 오류, 비활성입니다. 상태는 prop이 아니라 HTML 속성(`checked`, `aria-invalid`, `disabled`)으로 정합니다. 비활성은 투명도를 낮추지 않고 `muted` 면을 써서 대비가 유지됩니다.

## API 레퍼런스

`<input>`의 모든 속성과 `ref`를 받습니다(`type`은 `checkbox`로 고정입니다). 정의된 prop은 없습니다. 체크 표시는 `::after`로 그리고 지름은 20px입니다. 중간 상태(`indeterminate`)는 아직 지원하지 않습니다.

## 접근성

- 네이티브 `<input type="checkbox">`라서 역할과 선택 상태를 브라우저가 알려 주고, 스페이스로 켜고 끕니다.
- 그룹의 이름은 `fieldset`과 `legend`로 달아 주십시오.
- 체크 표시는 체크 모양과 테두리 색이 함께 바뀌어 색에만 기대지 않습니다.
- 체크하면 0.32초 튀어 오르고, 해제하면 채움과 체크 표시가 0.2초 동안 줄어들며 사라집니다. 처음 그려질 때는 움직이지 않으며 감소 모션이면 꺼집니다.
- 키보드 포커스는 두 겹 링(`ring-2 ring-ring`, 간격 2px)으로 보입니다. 오류는 `aria-invalid`로 알리고 안내 문구는 `aria-describedby`로 연결하십시오.
- 고대비(forced-colors) 모드에서는 브라우저 기본 체크박스로 돌아가고, 직접 그린 체크 표시와 채움은 숨깁니다. 비활성이면서 체크된 상자의 체크 표시는 배경색을 써서 대비를 확보합니다.
- 입력 칸만으로는 지름이 20px라 터치 영역이 24px에 못 미칩니다. 문서 예시처럼 `Label`(`htmlFor`)과 함께 써서 글자까지 눌리게 하십시오.
